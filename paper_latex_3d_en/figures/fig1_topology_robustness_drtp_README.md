# Fig. 1 editable source

This figure is an original, editable SVG schematic for the current
DRTP-SG-MAPPO topology-robustness research line. Its panel geometry, text,
arrows, relation paths, graph nodes, terrain, and failure marker are native SVG
objects. The four role illustrations are original PNG assets held separately in
`assets/fig1_role_icons/` so they can be replaced without redrawing the figure.

## Scope

It defines only the task, topology reconfiguration, and actor information
boundary. It makes no claim about strict recovery, information loss, numerical
performance, or DRTP superiority.

## Editing

Open `fig1_topology_robustness_drtp.svg` directly in Adobe Illustrator. The
UAV role illustrations are linked assets; all labels, relation lines, panel
frames, terrain, and legend are native SVG objects. Preserve the role/relation
colors when updating the figure so later figures share a consistent visual
vocabulary.

## Export

For manuscript submission, export an embedded-font PDF. Keep this SVG as the
editable master. Do not rasterize labels, arrows, link types, or icons.
