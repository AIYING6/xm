# Fig. 1 V1 对照与 V2 精修记录

## 参考图中继承的视觉结构

- 四联布局：左上任务场景、右上失效前后、左下 CTDE 总流程、右下编码器放大图；
- 白底、细黑边框、左上角面板标记 `(a)`--`(d)`、底部统一图例；
- 角色颜色与关系线型跨面板一致；
- 任务场景和编码器流程均使用由左向右的可追踪信息流。

## V1 与参考图仍不一致之处

| 项目 | V1 状态 | V2 精修 |
|---|---|---|
| (a) 信息标签 | P 标签与蓝色点线局部重叠 | 添加浅色底衬，提升阅读性。 |
| (c) 闭环表达 | 只画出 actor 到 action，没有显式环境返回流 | 增加 3DOF environment 方块和返回 recipient-specific P/C 的虚线。 |
| (d) 融合逻辑 | 公式存在，但“来源保持”和“冲突偏移”不够突出 | 将融合方块改为 source-preserving fusion，并直接标注 conflict-conditioned deviation 和 `Δ(0)=0`。 |
| 底部图例 | 角色圆点在宽轴中视觉上偏扁 | 改为紧凑圆角色标，与角色配色一致。 |
| 方法内容 | 参考图使用旧三关系 EA-RG 组件 | V1/V2 均明确改为两来源 PCRF-R2；不保留 Task-Support、Gate Prior、union residual 或 Role-Pair gate。 |

## 有意保留的不一致

参考图的山地背景、旧任务图中的 Task-Support 链和 EA-RG 多关系编码器未被复刻，因为它们不属于冻结的 v1.9 PCRF-R2 科学对象。V2 以简洁矢量角色符号、P/C 证据流和 CTDE 边界替代这些内容。
