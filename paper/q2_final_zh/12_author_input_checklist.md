# 12 作者输入清单

以下信息不能由代码仓库或实验结果推断，需要作者在投稿前提供。

## A. 投稿目标

- [ ] 中文目标期刊名称；
- [ ] 文章栏目/类型；
- [ ] 中文摘要字数限制；
- [ ] 是否要求英文题名、英文摘要和英文关键词；
- [ ] 图表单双栏尺寸、文件格式和分辨率；
- [ ] 参考文献格式与数量限制。

## B. 作者信息

- [ ] 全部作者中文姓名及顺序；
- [ ] 作者单位、城市、邮编；
- [ ] 通讯作者和电子邮箱；
- [ ] 作者贡献说明；
- [ ] 基金项目、编号及规范名称；
- [ ] 利益冲突声明。

## C. 开放与复现

- [ ] 代码公开范围与仓库地址；
- [ ] 正式模型检查点是否公开；
- [ ] evaluation tape、raw metrics 和统计脚本是否公开；
- [ ] 数据/代码公开时点；
- [ ] 匿名审稿阶段是否需要匿名仓库。

## D. 结果完成后确认

- [ ] 正式归档 SHA256 与本地文件一致；
- [ ] 十个最终检查点 hash 完整；
- [ ] 五个训练种子全部保留；
- [ ] 机器裁决已由作者阅读确认；
- [ ] 所有主文表格可追溯到机器产物；
- [ ] 不利种子和历史 FAIL/NO-GO 未被删除；
- [ ] 中文摘要与结论未超过机器裁决允许的主张边界。

## E. 当前不需要作者提供

在正式云端实验尚未完成时，不需要人工填写任何性能数字，也不需要提前选择“最好结果”。
