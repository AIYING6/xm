# 术语与主张边界

## 术语表

| 术语 | 本文固定含义 | 禁止替换为 |
|---|---|---|
| UTR-SG-MAPPO（UTR） | 六个扰动组条件均匀采样的匹配 Single-Graph MAPPO | 普适最优或稳定算法 |
| SNR-SG-MAPPO（SNR） | 固定非均匀扰动组权重的受控比较器 | 经调参的“最优静态方案” |
| DRTP-SG-MAPPO（DRTP） | 基于已完成 episode return 的有界在线组权重比较器 | 已证实可靠的主算法 |
| nominal anchor | 固定 50% nominal episode 暴露 | 每个 seed 的 nominal 保证 |
| F0 | 冻结的 canonical failure 条件 | 一般故障分布 |
| `J_OOD_mean/worst` | 冻结 timing、duration、compound 条件上的平均/最差得分 | 任意未见拓扑的泛化保证 |
| risk-set trigger validity | onset 前存活 episode 中的正确故障触发率 | 全体 episode 的策略性能 |
| pre-trigger termination | 故障 onset 前的合法终止，仍计入总体安全与回报 | 可删除的无效 episode |

## 中心论点

在冻结的中继故障拓扑重构任务中，前瞻性三方法、五训练种子和 12 个评估条件表明，固定均匀拓扑随机化在该新样本中优于固定非均匀和自适应扰动加权；训练分布加权的收益必须与 training-seed reliability 一同报告。

## 必须保留的边界

- 不把中继故障描述为必然信息黑障；
- 不把历史 DRTP 高收益与前瞻性比较合并排名；
- 不将灾难性 seed、onset 前 collision 或安全反转剔除；
- 不主张 DRTP/SNR/UTR 的普适最优、每 seed 稳定性、实飞或未见拓扑保证。
