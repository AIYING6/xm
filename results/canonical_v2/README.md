# Canonical v2 evidence package

This directory is the frozen destination for the first canonical confirmatory batch. It is intentionally empty of experiment outputs: no formal training or evaluation has been launched. The contract and required subdirectories are documented in `docs/CANONICAL_CONFIRMATORY_PROTOCOL_V2.md`.

Every future artifact must carry method, seed, config SHA, checkpoint SHA, code snapshot, protocol ID, and raw-episode provenance. Files marked `ENGINEERING_SMOKE_TEST_ONLY` must never be mixed with canonical evidence.
