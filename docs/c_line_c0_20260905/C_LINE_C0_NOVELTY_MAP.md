## Adversarial conclusion

N1 is an especially close threat: the candidate's relay assignment/routing/capacity/migration core is already an ILP-based UAV-relay reconfiguration problem. N2 separately removes any claim that failure-triggered online UAV reconfiguration is new. N5–N12 remove freshness, deadlines, deterministic multihop scheduling, and graph search as standalone novelty claims. No C-line novelty claim is presently authorized.
