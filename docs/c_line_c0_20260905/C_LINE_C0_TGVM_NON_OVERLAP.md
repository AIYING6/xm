# C-Line C0 TG-VM non-overlap audit

The proposed C-line candidate is not allowed to reduce to semantic mapping, inspection coverage, field-of-view selection, risk-map planning, or A* over a spatial value map.

| TG-VM hallmark | C-line proposed object | Verdict |
|---|---|---|
| Semantic map / inspection target value | Per-service freshness validity and hard service deadline | Different, if validity is a legal network-state predicate rather than a spatial value layer |
| FoV or visit action | Relay-route reservation/migration and service assignment | Different |
| Risk-weighted path cost | Capacity-feasible multihop service graph and disruption-free migration condition | Different |
| A* route to a location | Time-coupled assignment/routing/reconfiguration decision | Different in form |

This non-overlap is conditional on maintaining hard validity/capacity constraints. If future work turns service urgency into a spatial reward map and chooses an inspection route with A*, it becomes TG-VM-like and must be rejected.
