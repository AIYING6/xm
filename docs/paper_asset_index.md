## 6. 论文主张边界

可以写：

```text
EA-RG-MAPPO-S 在有限通信条件下表现更稳定，并降低碰撞率。
相对边特征增强了图注意力对物理关系和通信关系的建模。
分阶段随机通信半径微调改善了跨半径泛化。
```

谨慎写：

```text
EA-RG-MAPPO-S 在所有指标上全面超过所有基线。
```

不要写：

```text
当前方法实现了高精度目标意图识别。
当前实验已经验证完整 6DOF 空战、导弹、雷达、有人机协同系统。
```
