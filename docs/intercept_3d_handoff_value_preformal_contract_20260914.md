# 3DOF UAV 关系决策主线：正式实验前合同

## 1. 为什么当前不能直接进入正式多 seed 实验

现有 moderate 3DOF 拦截带已经完成了两个必要的开发验证：局部角色图没有读取隐藏目标状态，且局部图与无图策略都能在同一任务上学习。可是，容量匹配无图 MLP 的端点成功率为 96.7%，局部图为 100.0%（均为 seed 5203 的开发性结果）。这说明当前任务可被较大无结构网络近乎完全解决，不能把局部图的早期优势解释为关系结构机制的收益。

这不是终止项目，而是明确了需要修复的唯一缺口：任务必须出现一个由合法关系状态决定、且会改变最优协同选择的真实决策切换。

## 2. 拟研究问题：有限中继机会下的定时信息交接

在保留三架异构 UAV、3DOF 飞行动力学与离散原子飞行动作的前提下，构造“定时信息交接”任务。侦察 UAV 获取目标航迹；中继 UAV 拥有有限的交接机会，必须在“立即转发当前航迹”与“为后续航迹重构位置/链路”之间作选择；攻击 UAV 则必须结合航迹新鲜度、可达通信关系和末端攻击几何确定后续机动。该设计的关键不是给中继增加任意新按钮，而是使现有移动、可达关系与消息新鲜度共同决定某次交接的机会成本。

该问题的第一项事实已由零训练脚本验证：存在两个合法可达上下文，且“保留当前服务航路”与“迁移至后续服务航路”的偏好会反转，并使阶段性目标服务终点发生不同结果。服务航路是任务规划器公开发布的相对航路点；它不含目标真值、未来目标机动或其他无人机的隐藏状态。阶段性终点要求合法的中继目标信息交付；攻击窗口作为下游物理遥测独立记录，避免用追击控制器碰撞混淆 G0。

## 3. 拟方法与受控变量

候选方法为**交接价值条件化的局部关系策略**。在不恢复隐藏目标信息的前提下，策略从本地观测、已送达消息的来源/年龄、可见链路和角色元数据中构造合法候选交接关系；一个声明的关系价值头对这些关系评分，并以此条件化动作分布。

正式比较中的唯一方法变化是该关系价值条件化路径。所有方法均使用相同的：动力学、原子动作、奖励、PPO、训练预算、执行期信息、交接动作可用性和 endpoint tape。主要对照是参数量匹配的无结构 MLP；关键消融是将合法交接关系标签打乱，但保留网络容量与所有其他输入。

## 4. 进入正式实验前的五个门槛

| 门槛 | 需要证明的事 | 允许的证据 | 不允许的替代解释 |
|---|---|---|---|
| G0 决策切换 | 两种交接选择在不同上下文中会反转最优性并改变结局 | 脚本化合法控制器/反事实回放 | 仅凭奖励差或直觉 |
| G1 信息边界 | actor 不利用隐藏目标状态 | logits 不变性与字段审计 | “图编码器应当不会泄漏” |
| G2 非饱和可学性 | 无结构基线能学但不能轻易满分 | 小规模独立 seed pilot | 单个随机轨迹 |
| G3 机制信号 | 方法确实改变交接分配，并出现预设端点差异 | 小规模配对 pilot 与遥测 | 仅总回报提高 |
| G4 可识别消融 | 打乱关系语义后仍可训练、容量一致 | 配置/参数/接口审计 | 事后删掉不利消融 |

仅在 G0--G4 全部通过后，才冻结正式代码、种子、训练预算、评估带和统计计划。此前所有输出都标记为 development，不进入论文主结果。

## 5. 已知证据与边界

- `results/development/timed_handoff_intercept_3d_g0_incremental_reward_20260914/timed_handoff_g0_report.json` 为当前冻结候选的 G0 development-only 审计。在六个独立物理随机种子上，当前授权上下文中保持当前服务航路为 6/6 成功、迁移为 0/6；后续刷新上下文中保持为 0/6、迁移为 6/6。该结果只证明任务存在可达且方向相反的服务选择，**不证明任何学习方法有效**。

- `results/development/timed_handoff_3d_credit_path_incremental_reward_20260914/credit_path_report.json` 是不训练的信用路径审计。它显示在两个上下文中，成功控制器的累计阶段任务回报均高于对应失败控制器（当前授权约 4.99 对 0.55；后续刷新约 5.11 对 0.74）。此前的旧拦截回报会反向偏好失败路线，因而在当前派生任务中被禁用；保留碰撞与约束终止/惩罚。该审计证明训练目标与受控任务终点排序一致，不证明 PPO 已可学习。

- `scripts/smoke_test_intercept_3d_local_role_graph.py` 已验证局部图对隐藏目标变化不敏感。
- `results/development/intercept_3d_local_role_graph_learnability_pilot/seed5203/ppo/endpoint_evaluation.csv` 证明局部图在现有 moderate 带可学习。
- `results/development/intercept_3d_local_role_graph_capacity_matched_control/seed5203/ppo/endpoint_evaluation.csv` 表明容量匹配 MLP 也几乎饱和，因此不能支持现有局部图的结构性主张。

短预算 plain-MAPPO 开发 run（每个 24,576 environment steps）尚未达到 G2：原始回报版本只学习到当前授权上下文；两次奖励修复版在固定短预算中仍为零。最近的承诺级 seed73301 run 也在两个上下文均为零；只读行为追踪显示其在后续刷新上下文会选择重构但仍无法完成服务。字段比对发现该 runner 使用了默认 `target_init_range_scale=1.0`，而 G0 使用经验证的 `0.65`，使训练物理初态与 G0 合同不一致。对齐后的 seed73302 虽在后续刷新达到 100%，却在当前授权为 0%，且策略在所有阶段选择重构；单上下文 seed73303 也未稳定保留当前服务。审计表明当前高层动作仍被拆成连续八个重新选择，造成当前授权成功路径的探索信用过稀。上述 run 均属旧逐步动作接口诊断，绝不并入正式统计。

这些结果只用于确定下一步设计，均不是正式论文证据。

## 6. 紧接着的执行动作

G0 与 G1 已通过。V2 option 接口消除了当前授权的全零，但 update48 在两个上下文均达到 100%，仍属于饱和开发带。零训练扫描表明未来航路偏移一旦超过 1500 就迅速破坏脚本可达性；因此不把空间距离作为难度调参轴。相反，V3 只将后续刷新所需的连续合法服务 hold 从 8 提升至 16：G0 在六个物理 seed 中仍为 6/6 反向可达，而 hold=20 已降至 3/6。V3 保留 option 化承诺（一项高层中继选择被保持 8 个原始 3DOF 物理步，低层追踪仍逐步闭环）、相同动力学、服务终点、观测、奖励和两个承诺动作；它仅要求重构后的服务更持久。

此前 V3 学习轨迹出现“单一承诺塌缩”：一个 seed 仅完成当前授权，另一个仅完成后续刷新。审计确认这不是额外调参的理由，而是宏动作接口的因果不一致：环境只读取中继机的高层承诺，但 PPO 同时对侦察机与攻击机两个被忽略的占位动作计算策略比值和熵。V4 因而冻结 `relay_only` actor-action contract：actor 损失、KL 和熵只覆盖中继承诺；集中式 critic 仍接收全部三机状态，环境、奖励、观测、动作集合、预算和低层物理控制均不变。默认训练路径仍是历史的 `all_agents`，故该开关不回写历史实验。V4 必须使用与 G0 完全一致的 `target_init_range_scale=0.65`、服务半径、授权/分支时刻、目标策略和信息边界；运行前由 `scripts/smoke_test_commitment_handoff_mappo.py` 检查该不变量。仅当三个独立 V4 seed 经两个上下文各 40 回合只读评估，且每个上下文至少两个 seed 落入预注册的中等、非饱和成功带，G2 才通过。G2 未通过前，不实现候选关系价值网络，也不启动任何正式长训练。

## 7. G3 方法设计的预先约束

当前服务类别在任务开始时作为公开任务约束提供给 actor。它用于保证两种承诺都在合法、可解释的任务上下文中被比较；因此，G2 即使通过，也**不能**作为“模型从关系结构中发现了服务价值”的证据。G2 只回答任务是否可学且不饱和。

若进入 G3，候选机制必须同时满足以下设计与审计条件：

1. 候选关系价值仅使用 actor 已见的本地消息年龄/来源、可见链路有效性、公开服务路点与角色标识；不得读取目标真值、未来目标状态、集中式 critic 特征或评估带信息。
2. 输出必须是两个已存在合法承诺（保持当前服务、重构未来服务）的显式关系价值或差值，并以该值条件化中继的动作分布；不得通过扩宽通用 MLP、额外训练预算或辅助奖励取代该接口。
3. 主 MLP 对照与关系价值方法的参数量、PPO、奖励、观测、动作、物理步数、训练条件和 endpoint tape 必须匹配；唯一差异为关系价值条件化路径。
4. 机制消融仅打乱合法关系价值语义到承诺的映射，保留输入维度、参数量、优化器和采样流程。若打乱后性能或承诺选择行为不退化，G3 不通过，不进入正式多 seed 实验。
5. 行为遥测必须分开报告两类承诺的选择率、服务走廊进入率、消息年龄/链路状态与终局成功；总回报提升不能替代上述机制证据。

因此，候选方法的论文主张上限被预先限定为：它是否改善了**在已观测的合法关系状态下**对两类服务承诺的选择；而不是声称从公开上下文本身“推断”或恢复了隐藏信息。
