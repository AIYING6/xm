# 3DOF UAV 关系决策主线：正式实验前合同

## 1. 为什么当前不能直接进入正式多 seed 实验

现有 moderate 3DOF 拦截带已经完成了两个必要的开发验证：局部角色图没有读取隐藏目标状态，且局部图与无图策略都能在同一任务上学习。可是，容量匹配无图 MLP 的端点成功率为 96.7%，局部图为 100.0%（均为 seed 5203 的开发性结果）。这说明当前任务可被较大无结构网络近乎完全解决，不能把局部图的早期优势解释为关系结构机制的收益。

这不是终止项目，而是明确了需要修复的唯一缺口：任务必须出现一个由合法关系状态决定、且会改变最优协同选择的真实决策切换。

## 2. 拟研究问题：有限中继机会下的定时信息交接

在保留三架异构 UAV、3DOF 飞行动力学与离散原子飞行动作的前提下，构造“定时信息交接”任务。侦察 UAV 获取目标航迹；中继 UAV 拥有有限的交接机会，必须在“立即转发当前航迹”与“为后续航迹重构位置/链路”之间作选择；攻击 UAV 则必须结合航迹新鲜度、可达通信关系和末端攻击几何确定后续机动。该设计的关键不是给中继增加任意新按钮，而是使现有移动、可达关系与消息新鲜度共同决定某次交接的机会成本。

该问题的第一项事实已由零训练脚本验证：存在两个合法可达上下文，且“保留当前服务航路”与“迁移至后续服务航路”的偏好会反转，并使阶段性目标服务终点发生不同结果。服务航路是任务规划器公开发布的相对航路点；它不含目标真值、未来目标机动或其他无人机的隐藏状态。阶段性终点要求合法的中继目标信息交付；攻击窗口作为下游物理遥测独立记录，避免用追击控制器碰撞混淆 G0。

## 3. 拟方法与受控变量

候选方法为**交接价值条件化的局部关系策略**。在不恢复隐藏目标信息的前提下，策略从本地观测、已送达消息的来源/年龄、可见链路和角色元数据中构造合法候选交接关系；一个声明的关系价值头对这些关系评分，并以此条件化动作分布。

正式比较中的唯一方法变化是该关系价值条件化路径。所有方法均使用相同的：动力学、原子动作、奖励、PPO、训练预算、执行期信息、交接动作可用性和 endpoint tape。主要对照是参数量匹配的无结构 MLP；关键消融是将合法交接关系标签打乱，但保留网络容量与所有其他输入。

## 4. 进入正式实验前的五个门槛

| 门槛 | 需要证明的事 | 允许的证据 | 不允许的替代解释 |
|---|---|---|---|
| G0 决策切换 | 两种交接选择在不同上下文中会反转最优性并改变结局 | 脚本化合法控制器/反事实回放 | 仅凭奖励差或直觉 |
| G1 信息边界 | actor 不利用隐藏目标状态 | logits 不变性与字段审计 | “图编码器应当不会泄漏” |
| G2 非饱和可学性 | 无结构基线能学但不能轻易满分 | 小规模独立 seed pilot | 单个随机轨迹 |
| G3 机制信号 | 方法确实改变交接分配，并出现预设端点差异 | 小规模配对 pilot 与遥测 | 仅总回报提高 |
| G4 可识别消融 | 打乱关系语义后仍可训练、容量一致 | 配置/参数/接口审计 | 事后删掉不利消融 |

仅在 G0--G4 全部通过后，才冻结正式代码、种子、训练预算、评估带和统计计划。此前所有输出都标记为 development，不进入论文主结果。

## 5. 已知证据与边界

- `results/development/timed_handoff_intercept_3d_g0_compactroute_20260914/timed_handoff_g0_report.json` 为 G0 的 development-only 审计。在六个独立物理随机种子上，当前授权上下文中保持当前服务航路为 6/6 成功、迁移为 0/6；后续刷新上下文中保持为 0/6、迁移为 6/6。该结果只证明任务存在可达且方向相反的服务选择，**不证明任何学习方法有效**。

- `scripts/smoke_test_intercept_3d_local_role_graph.py` 已验证局部图对隐藏目标变化不敏感。
- `results/development/intercept_3d_local_role_graph_learnability_pilot/seed5203/ppo/endpoint_evaluation.csv` 证明局部图在现有 moderate 带可学习。
- `results/development/intercept_3d_local_role_graph_capacity_matched_control/seed5203/ppo/endpoint_evaluation.csv` 表明容量匹配 MLP 也几乎饱和，因此不能支持现有局部图的结构性主张。

这些结果只用于确定下一步设计，均不是正式论文证据。

## 6. 紧接着的执行动作

G0 已通过。下一步只做 G1/G2：先将阶段任务接入严格局部信息的普通、容量受控 MAPPO，完成字段审计与隐藏状态 logits 不变性测试；随后以少量开发 seed 检验该基线是否可学习且未饱和。G2 未通过前，不实现候选关系价值网络，也不启动任何正式长训练。
