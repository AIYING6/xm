# Role-Gate development protocol

All Phase 2I-A architecture diagnostics are `DEVELOPMENT_ONLY`, use only seeds `101, 202, 303`, and use deterministic forward/backward/intervention checks rather than canonical training. No seed 0–4, canonical test scenario, formal evaluation tape, or canonical performance result is used.

Candidates: G0 no gate, G1 shared role-pair gate, G2 relation-conditioned role-pair gate. Ordered selection criteria are functional validity, non-degeneracy, stability, non-worsening development behavior if later run, then parsimony.
