# DRTP 投稿收敛计划（冻结版）

**生效日期：** 2026-08-28  
**目的：** 将项目从算法搜索切换为投稿准备；以现有证据形成一篇边界清楚、可复核的中文应用型 UAV/MARL 稿件。  
**不改变的历史结论：** 历史开发 `NO-GO`、held-out v2 `FAIL`、DRTP Q2 算法判定 `LIMITATION_ONLY` 均永久保留。

## 1. 冻结决定

自本计划生效起，不再启动以下活动：

- DRTP、R-DRTP、EGTR、SNR 或其他稳定化/替代算法的新训练；
- 任何新的 3M、5M 或 10M 训练；
- 为改变结果而更换、删除、补选或延长训练 seed；
- 因后续评价结果修改 DRTP、PPO、环境、奖励、故障语义、网络或既有统计阈值。

`DRTP Training-Failure Mechanism V1` 的云端 1M 数据因实际
`run_manifest.config.seed=1901` 而非目录标注的 2601--2603，标记为
`TECHNICAL_INVALID`。该归档仅保留为工程故障记录，不进入论文的性能、可靠性或机制证据，也不触发重跑。

## 2. 投稿主证据层级

| 层级 | 资产 | 可支持的陈述 | 不可支持的陈述 |
|---|---|---|---|
| 主因果消融 | 2301--2305、UTR vs DRTP、同构 10M 最终检查点 | 在该正式 cohort 中，有界自适应加权相对均匀加权的经验增益 | 跨 cohort、跨初始化的稳定优越性；对任意静态非均匀权重的必然优势 |
| 外部性能参考 | MAPPO-NoGraph 五 seed 10M | 无图 MAPPO 在同任务中的性能与安全位置 | 图结构、参数量或自适应加权的单独因果作用；外部方法排行榜 |
| 独立可靠性证据 | 2401--2405 三方法 cohort 与两张评价 tape | 正式正向与独立反向不能仅由评价 tape 更换解释 | 任一具体 RNG 源、policy basin 或优化机理是根因 |
| 历史背景 | 1901/1902、2001/2002/2003 与审计 | 训练风险必须被完整披露 | 与正式 cohort 合并成同质统计重复 |

## 3. 可执行的零训练收口工作

### 3.1 已有结果的可读性补全

在主文或补充材料中固定并核验：

1. mission score 的奖励组成、量纲/物理任务含义与成功、超时、碰撞之间的关系；
2. mission completion / success-at-horizon、碰撞、超时、约束违规的逐 seed 与汇总报告；
3. 故障退化量 \(D_c=J_{\mathrm{nominal}}-J_c\) 的逐 seed 和总体分解；
4. 触发风险集、故障前终止和 failure exposure 的技术语义；
5. 训练 cohort、评价 tape、统计独立单位之间的明确区分。

### 3.2 一次性未见条件评价（需独立执行授权）

允许的唯一新计算是**不训练**的附加未见条件评价。执行前必须单独冻结：

- 新的 onset、duration 和 compound 条件，且不属于已训练的十个成员；
- 完整 episode ID、条件清单、manifest 与 SHA256；
- 使用现有 final checkpoints；
- 所有方法、全部 checkpoint 与全部 episode 完整报告；
- 结果定位为 `additional held-out / exploratory unseen-condition evaluation`，不得倒写为原正式 cohort 的预注册 confirmatory OOD。

无论其结果方向如何，均不得修改算法或重新训练。

## 4. 稿件重构规则

正文按以下顺序组织：

1. 中继故障导致合法通信—任务支持路径重构；
2. 受约束的拓扑扰动训练问题与 DRTP；
3. 2301--2305 正式 cohort 的主消融、退化分解和安全权衡；
4. MAPPO-NoGraph 的外部性能参考及其不可归因边界；
5. 独立 cohort 与 cross-tape 可靠性限制；
6. 局限性和可复现性材料。

正文不展开旧 R-DRTP、EGTR 或无效 Mechanism V1 的方法公式与结果；它们不构成当前稿件的证据层。
哈希、合同 ID、逐文件审计和完整 manifest 移至补充材料/匿名复现包，正文只保留复现所必需的协议与统计定义。

## 5. 投稿前红队检查

在选刊前仅审查下列问题：

1. 创新是否被限制为“受约束自适应加权相对均匀加权”的经验比较？
2. 正式/独立 cohort 的方向反转是否被完整且不合并地披露？
3. 是否删除了 stable、consistent、universal、strict OOD 等不受支持措辞？
4. MAPPO-NoGraph 是否始终被限制为外部性能参考？
5. 每项主张是否具有相应的图、表、原始数据和合同来源？

红队通过后，停止继续扩展实验，进入目标期刊格式、匿名复现包和投稿元数据准备。

## 6. 当前状态

`SUBMISSION_CONVERGENCE_ACTIVE`：可继续零训练整理、一次性冻结的未见条件评价（仅在单独授权后）和稿件收口；不授权任何新训练或算法开发。
