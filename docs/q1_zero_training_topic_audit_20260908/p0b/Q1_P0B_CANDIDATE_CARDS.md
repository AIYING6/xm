# Q1-P0B 候选研究卡

## 候选 A：任务信息可行域（TIV）

**一句话问题。** 在动态通信故障下，UAV 团队能否通过物理机动保持“关键执行者在任务截止前获得合法、足够新鲜信息并完成任务”的未来可能性？

**新决策对象。** 对扩展状态 (s=(x,z,G,	au,p,phi)) 定义任务信息可行集：存在满足物理、安全和合法信息约束的分散策略，使任务在截止前完成；鲁棒版本要求对给定故障集合中的所有扰动成立。

**与常见对象的区别假设。** TIV 不等于图连通、不等于最小 AoI、不等于瞬时合法动作集，也不等于一般任务可达性；它把角色/来源、信息时效和未来运动诱导通信机会同时纳入任务完成条件。

**潜在理论核心。** 任务信息割；受限拓扑族上的可行性判据；TIV 集的递归保持条件；任务信息屏障或有限时域证书。

**资产复用。** 高。三机环境已有物理动作、运动诱导通信、节点故障、来源路径、缓存年龄/置信度和任务信息门控。

**主要风险。** 很可能退化为通信约束时序规划或标准 viability kernel 的换名；一般情形计算不可承受；若证书只依赖全局真值则不满足分散执行边界。

**零训练否证试验。** 构造三类严格反例，并证明至少一个非通用、可计算的命题；若做不到即关闭。

**P0B 裁决。** `CONDITIONAL_GO_TO_P0C_ONLY`。

## 候选 B：拓扑故障可辨识性与主动诊断控制

**一句话问题。** 当消息缺失既可能来自距离、丢包，也可能来自节点故障时，UAV 应如何选择带诊断价值的运动来区分原因并恢复协同？

**新决策对象。** 故障模式的可辨识集或 belief 收缩率；任务收益与诊断价值构成双重控制。

**近邻压力。** active information gathering、Dec-POMDP、VoI、故障诊断和 communicating unexpectedness 已覆盖“为减少不确定性主动行动/通信”的大部分空间：[Multi-Robot Active Information Gathering](https://arxiv.org/abs/1703.02610)、[Asking for Information in Multi-Agent POMDPs](https://doi.org/10.1109/LRA.2026.3703246)。

**资产复用。** 中。现有局部 message age 可复用，但故障先验、观测混淆和可控探测实验尚未冻结；当前 actor 可能很快直接区分故障。

**风险。** 为制造可辨识性必须重写故障观测模型，且容易成为标准 dual control/POMDP。

**P0B 裁决。** `NO_GO_CURRENT_REPOSITORY`。

## 候选 C：拓扑干预下的因果不变协同表示

**一句话问题。** 能否学习在拓扑删边/节点失效干预下保持任务因果结构、而不依赖训练图相关性的协同表示？

**新决策对象。** 拓扑干预等价类或结构不变表示。

**近邻压力。** graph OOD、动态图 MARL、跨规模图策略和 unexpectedness communication 已经密集；若没有可识别因果模型，方法只能成为新的正则项或 GNN 架构。

**资产复用。** 中高。已有多种故障与结构评估，但真实干预因果图和反事实标签不存在。

**风险。** 因果主张所需数据和识别假设远高于当前仿真资产；一区审稿会要求多个环境与更广图分布。

**P0B 裁决。** `NO_GO_FOR_COST_AND_IDENTIFIABILITY`。

## 候选 D：局部信息合同与可验证协同策略

**一句话问题。** 为异构角色规定局部可检查的信息合同，并证明合同满足时协作任务保持安全/可完成。

**新决策对象。** role-conditioned information contract；策略动作前的分散证书。

**近邻压力。** 形式化 resilient MAS、时序逻辑规划、CBF/shield 和分布式安全控制已覆盖合同、约束与证书思想：[Modelling Resilient Collaborative MAS](https://link.springer.com/article/10.1007/s00607-020-00861-2)、[Distributed Coordination Using Barrier Functions](https://doi.org/10.1109/TAC.2015.2444131)。

**资产复用。** 中高。现有 fresh-cache/action mask 可作为一个合同实例。

**风险。** 若合同由环境人工写死，贡献只是规则与掩码；若要学习合同，又回到安全表示学习并需要广泛验证。

**P0B 裁决。** `NO_GO_AS_STANDALONE_Q1_TOPIC`；可作为 TIV 的验证工具，而非独立主线。
