# C0R 反例与理论靶点审查

## 1. 严格反例 A：物理图不足以确定任务动作可行性

本地 `B_P0R_NATIVE_FRESHNESS` 构造了两个合法历史：它们在同一时刻具有相同 UAV 位置、物理拓扑、任务进度、角色和分配状态，但终端缓存年龄分别为 0 与 6。在冻结阈值 \(\tau_{\max}=5\) 下，前者允许任务动作，后者屏蔽该动作。因此

\[
\sigma_t^P(h_1)=\sigma_t^P(h_2),\qquad
\mathcal A_{\mathrm{feas}}(h_1)\neq\mathcal A_{\mathrm{feas}}(h_2).
\]

证据：`docs/b_line_p0r_20260905/p0r-execution/B_P0R_NATIVE_FRESHNESS_RESULT.json` 与 `docs/b_line_p1_20260905/B_LINE_P1_FORMAL_PROBLEM_FREEZE.md`。

该反例证明信息有效性状态是决策相关的；它不证明任何特定优化器或学习算法的新颖性。

## 2. 严格反例 B：短视服务选择可被跨时隙重构严格支配

沿用冻结的两时隙反例：唯一容量单元在时隙 0 可用于立即完成价值 6 的任务 A，或用于预留/迁移任务 B 的路径；任务 B 在时隙 1 截止，价值 10。短视规则选择 A 并使 B 失效，总价值 6；有限时域规则先迁移再服务 B，总价值 10。

\[
6>0\quad\text{（当前时隙）},\qquad 10>6\quad\text{（完整时域）}.
\]

证据：`docs/c_line_c0_20260905/C_LINE_C0_NONMYOPIC_COUNTEREXAMPLE.md` 与 `c0-execution/C_LINE_C0_NONMYOPIC_TRUTH_TABLE.csv`。

该反例证明问题类可以具有非短视性；N1 与 N11 已覆盖容量预留和无中断迁移，因此该反例不能单独构成贡献。

## 3. 候选理论靶点

| 靶点 | 可能命题 | 可证性 | 学术价值 | 最近邻/通用化风险 | 裁决 |
|---|---|---|---|---|---|
| T1 有效性状态充分性 | 在确定性传输和冻结失效规则下，物理图加最小令牌证书是控制的 Markov 充分统计量 | 高 | 中：澄清状态定义 | 很可能只是标准状态扩充/POMDP belief 的特例；N16/N17 已覆盖历史表征 | 不足以支撑一区算法 |
| T2 分解与整数性 | 在树/森林、单路径、单位容量和层级期限下，感知—路由—服务问题可无损分解或 LP 松弛整数 | 中 | 中高（若成立） | 易退化为时间扩展流、匹配、区间/期限调度的已知性质；N7/N8/N10 覆盖结构调度 | 未发现独特结构来源 |
| T3 有效性保持重构证书 | 给定旧/新路径与令牌期限，存在不中断迁移的充要条件 | 高 | 中高 | N1 已给 UAV 无中断迁移条件；N11/N12 覆盖 make-before-break 与状态一致性 | 实质重叠，淘汰 |
| T4 在线竞争界 | 在因果故障、有限容量和硬过期下，在线策略相对离线最优有常数竞争比 | 低到中 | 高 | 无限制对抗故障下可能不存在常数界；加入强假设后可能退化为已知在线调度 | 尚无可信命题 |
| T5 分散可行性证书 | 局部令牌/容量证书可保证所有执行动作信息合法，并在某类图上完备 | 中 | 高 | 声明安全容易，完备性受全局容量与并发流耦合破坏；网络一致更新和分布式调度近邻强 | 有概念价值，但未形成可证、非通用结构 |

## 4. 理论审查结论

五个靶点中：T1 可证但贡献偏状态建模；T3 被直接近邻覆盖；T2、T4、T5 尚未找到同时满足“可证、非通用、与 UAV 任务紧密相关”的结构。按照预先冻结的一票否决规则，目前不存在足以授权算法实现的理论靶点。
