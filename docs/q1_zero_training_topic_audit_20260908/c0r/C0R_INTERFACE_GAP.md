# C0R 本地资产与接口差距

| 要素 | 三机 3DOF 环境 | 冗余拓扑六机环境 | C0R 最小问题需求 | 处理结论 |
|---|---|---|---|---|
| 动态节点/链路故障 | 有动态中继节点故障 | `set_failure` 支持边/节点屏蔽 | 外生、因果故障 | 可复用故障语义与测试框架 |
| 信息年龄/缓存 | 消息年龄、目标缓存年龄/置信度、路径来源 | 终端令牌含生成时刻、接收时刻、路径和 age | 信息有效性状态 | 可复用状态与遥测思想 |
| 合法信息边界 | 图目标信息受掩码；本地缓存决定目标信息 | 终端服务动作由 fresh token 掩码 | 严格分散合法信息 | 可复用审计原则，需重做新接口证明 |
| 主动感知 | 物理动作间接影响感知 | scout 动作选择对象 | 有成本/容量的主动感知 | 六机已有动作外形，但当前全覆盖、无直接成本，决策过于平凡 |
| 任务服务 | 攻击/拦截依赖目标信息 | terminal 选择对象并移动完成 | 依赖有效证书的服务动作 | 可复用抽象，需修复联合动作掩码闭包 |
| 路由选择 | 无策略路由动作 | 自动遍历所有可达中继 | 策略可选路径/下一跳 | 缺失，必须公开新增 |
| 中继分配/激活 | 无 | relay 非 idle 动作 transition-inert | transition-effective 中继决策 | 缺失，必须公开新增 |
| 容量竞争 | 无显式链路流容量 | 自动广播，无共享容量冲突 | 链路/中继容量与冲突 | 缺失，必须公开新增 |
| 切换/迁移代价 | 无 | 无 | 重构时延、资源或 make-before-break | 缺失，必须公开新增 |
| 高保真/硬件证据 | 轻量仿真 | 轻量确定性环境 | 一区通常需要更强系统证据 | 缺失；未来成本高 |

## 结论

现有仓库能复用的是故障语义、信息年龄、图接口、训练基础和审计工程，不能复用为事实的是主动路由、容量竞争、迁移和真实通信系统。若未来重新提出相关课题，应将其作为新基准公开设计，而不是声称原环境只需小改。
