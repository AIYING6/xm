# C0R 最小形式问题

## 1. 目的

本文件冻结用于新颖性攻击的最小问题，不代表将要实现的环境或算法。其作用是避免使用“智能重构”“信息有效性”等宽泛词语逃避最近邻比较。

## 2. 状态与外生过程

离散时刻为 (t=0,\ldots,H)。物理网络为有向图

\[
G_t^P=(V,E_t^P),
\]

其中 (E_t^P) 由位置、无线可达性和外生节点/链路故障决定。故障过程不受策略控制，且策略不得读取未来故障。

对任务对象 (k\in K)，信息令牌

\[
c=(k,s,g,p,t_g,t_r)
\]

记录对象、来源传感器、生成时刻、传输路径和接收时刻。接收端 (d) 在时刻 (t) 对对象 (k) 的有效性为

\[
\eta_{dk,t}=\mathbf 1\{c\text{ 已到达 }d,\ t-t_g\le \tau_k,\ c\text{ 的来源与路径满足冻结合法性规则}\}.
\]

由此定义信息有效性图 (G_t^V=(D\cup K,E_t^V))，其中 ((d,k)\in E_t^V\) 当且仅当 \(\eta_{dk,t}=1\)。

## 3. 决策变量

- (u_{sk,t}\in\{0,1\})：传感器/侦察 UAV (s) 是否更新对象 (k)；
- (x_{ij}^{c,t}\in\{0,1\})：令牌 (c) 是否在时刻 (t) 使用链路 ((i,j))；
- (y_{ij,t}\in\{0,1\})：是否激活/保留传输或中继关系；
- (z_{dk,t}\in\{0,1\})：任务执行 UAV (d) 是否执行依赖对象 (k) 信息的服务动作；
- (m_{ij,t}\in\{0,1\})：是否发生路由/中继切换，用于表达迁移代价或 make-before-break 资源占用。

## 4. 最小硬约束

1. 感知资源：\(\sum_k u_{sk,t}\le C_s\)；
2. 链路/中继容量：\(\sum_c x_{ij}^{c,t}\le C_{ij,t}y_{ij,t}\)；
3. 因果流守恒：令牌只能在生成后沿当前合法边传播；
4. 信息合法性：\(z_{dk,t}\le\eta_{dk,t}\)；
5. 服务互斥/任务期限：每个执行者每时刻服务有限对象，且关键任务在截止前完成；
6. 重构一致性：切换期间旧路径释放和新路径建立遵守冻结的 break-before-make 或 make-before-break 规则；
7. 信息边界：分散策略只能使用本地合法观测、接收令牌和自身历史。

## 5. 目标

一种代表性有限时域目标为

\[
\max \sum_{t,k,d} w_k z_{dk,t}
-\lambda_m\sum_{t,i,j}m_{ij,t}
-\lambda_e\sum_{t,s,k}u_{sk,t}
-\lambda_c\sum_{t,c,i,j}x_{ij}^{c,t},
\]

同时对关键任务保留硬期限/有效性约束。权重仅用于定义问题；本轮不选择数值。

## 6. 与本地接口的关系

`envs/redundant_topology_uav_env.py` 已原生提供 (u) 的部分语义、(z) 的部分语义、令牌年龄以及 (z\le\eta) 的动作掩码。但 (x,y,m) 不存在：中继动作被明确忽略，路由为冻结广播式网络操作。因此该形式问题不是当前环境的未修改版本。

## 7. 形式化结果

该模型清楚表达了一个真实序贯问题，但从算法角度自然落入 time-expanded multi-commodity flow、任务调度与重构 MILP 的交集。问题写清楚并不等于新颖性成立。
