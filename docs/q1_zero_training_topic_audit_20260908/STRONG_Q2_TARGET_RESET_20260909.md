# DRTP 强二区目标重置

**日期：** 2026-09-09
**裁决：** `STRONG_Q2_CONDITIONAL_GO_EXISTING_DRTP_CORE`

## 1. 目标变化不等于证据标准下降

项目目标由一区调整为强二区后，不再要求发现一个独立的新数学对象或非平凡定理。但是，强二区仍至少需要：清楚的问题价值、可复现的受控主比较、跨独立训练队列的重复方向、对强近邻方法的诚实定位，以及不超过证据的机制解释。

P0C 对任务信息可行域（TIV）的 `NO_GO` 继续有效。TIV 可以作为解释拓扑退化为何影响协作的信息语言，不能作为独立算法贡献重新启动，也不允许据此开发 TIV critic、barrier-MAPPO 或新环境。

## 2. 已核验的正式证据

### 2.1 可作为正文核心的证据

- 最终 A cohort：UTR 与 DRTP 的扰动回报均值分别为 177.02 和 216.66，DRTP 平均差为 +39.64；DRTP 的最差 seed 为 191.49，UTR 为 79.75。
- 最终 B cohort：UTR 与 DRTP 的扰动回报均值分别为 187.18 和 210.34，DRTP 平均差为 +23.15；DRTP 的最差 seed 为 172.03，UTR 为 164.98。
- structural held-out evaluation：A、B 两批的结构扰动均值均为 DRTP 高于 UTR，但该结果应按原协议的证据层级表述，不能扩写为通用 OOD 保证。
- PLR-style 外部比较：A 中 DRTP 的扰动回报高于 PLR-style；B 中 PLR-style 回报更高，而 DRTP 的 timeout 更低。该结果支持“DRTP 与通用优先级训练具有竞争力”，不支持“全面优于 PLR”。

### 2.2 只能作为边界或补充材料的证据

- 2×2 factorial completion 中，UTR、Fixed-DRTP、Random-DRTP、DRTP 的扰动回报均值分别为 201.18、199.72、198.92、197.58。该批不能证明 topology semantics 或持续 adaptive update 的必要性。
- 修复 fault timing 后的 6-UAV v2 中，前四个 seed 的 UTR–DRTP 端点完全相同，第五个 seed 的 DRTP 在所有条件上更差。该实验不能支持 DRTP 的跨规模性能优势；最多用于说明当前 6-UAV 任务/指标缺乏方法可区分性以及扩展边界。
- 历史开发队列、失败的稳定化版本和旧 6-UAV 无效故障实验不得并入正式样本量。

## 3. 强二区论文的可发表核心

### 单句论题

在保持策略结构、PPO 目标、任务接口、训练预算和故障支持集合不变时，基于拓扑组难度的有界训练暴露重分配，在两个独立冻结训练 cohort 中重复改善了三机异构 UAV 任务的故障条件端点，并在结构扰动和通用优先级对照下表现出有边界的竞争性。

### 允许的三项贡献

1. **受控问题贡献：** 将动态通信拓扑故障下的训练暴露分配隔离为唯一主要实验变量。
2. **方法贡献：** 提出带 nominal anchor 和概率边界的拓扑组自适应暴露分配机制，而不改变 actor、critic 或 PPO 目标。
3. **经验贡献：** 在两个独立冻结 cohort、结构扰动带和 PLR-style 对照中刻画平均收益、lower tail、timeout 与队列差异。

不得把消融写成“两个组件已分别得到因果验证”，不得写跨规模优势，也不得把采样遥测写成策略机制证明。

## 4. 最具性价比的执行路线

### P0：立即冻结范围

- 继续以 3-UAV 最终 A/B 为主结果。
- TIV 只保留为问题解释，不作为新方法。
- 6-UAV v2 与 factorial ablation 降为边界证据或补充材料。
- 不再追加 seed，不再调 DRTP，不再修 6-UAV 以追求正结果。

### P1：零训练证据重建

1. 建立唯一正式资产清单和 SHA256，明确 A/B、held-out、PLR、factorial、6-UAV 的证据层级。
2. 重算训练 seed 级效应量和 bootstrap 置信区间；episode 只用于估计每个训练 seed 的端点，不扩充独立样本量。
3. 重写论文结果结构：主比较 → 可靠性权衡 → held-out → PLR → 机制遥测 → 边界实验。
4. 将历史实验全部移出主结果，只在补充材料中说明开发过程与失败边界。

### P2：唯一允许的新证据缺口

只允许补**统一硬件上的运行开销测量**，因为它不改变算法、不依赖重新追求性能优势，并直接回答方法是否轻量。记录 wall-clock、sampler update time、峰值显存和参数量。

如果运行时间不能从现有日志可靠恢复，只允许短时、等配置 benchmark；不得把短 benchmark 混为 10M 性能训练。

## 5. 强二区门槛

完成以下条件后进入投稿，而不是继续开发：

- 两个最终 A/B cohort 的来源、种子、固定端点和评估带能够逐文件追溯；
- seed 级统计完整，正文不使用 episode-level 伪重复；
- PLR 的双 cohort 权衡被准确呈现；
- factorial 与 6-UAV 的负向/无区分结果未被隐藏，也未被放大为主结论；
- 运行开销有真实测量，或明确标记为未测；
- 标题、摘要和贡献不含 universal、guarantee、all seeds、cross-scale advantage 等超证据表述。

达到这些条件后，项目具备“强二区可投”的完整性；是否录用仍取决于目标期刊对算法新颖性与单一仿真平台证据广度的要求。若继续追求显著更高上限，应另做零训练新颖性审查，而不是在本文中叠加新算法。
