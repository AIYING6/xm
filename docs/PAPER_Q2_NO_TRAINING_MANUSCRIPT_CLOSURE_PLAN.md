# 中文论文无新增训练收口计划

**状态：** 已执行无新增训练修订，科学主线冻结。

**适用稿件：** `paper/q2_final_zh/main_zh.md`

## 1. 本轮可以直接完成的内容

本轮只处理不依赖新训练的投稿质量事项：

- 统一“相对于均匀加权的经验增益”与“不能证明在线自适应必要性”的主张边界；
- 明确 UTR–DRTP 是参数匹配的内部主消融，不把缺少可比外部基线误写成击败外部方法；
- 在局限性中显式保留固定非均匀权重对照缺失；
- 保留正式五种子、共同 10M 最终检查点、12,000 条原始记录、seed2302 正常工况退化以及历史开发/留出失败结论；
- 将数据与代码、作者信息、基金和利益冲突改为诚实的投稿前元数据说明，避免把待填写信息误写成已完成事实；
- 继续维持中文主稿路线，不启动英文全文。

## 2. 当前证据支持的论文主张

在冻结的三无人机轻量 3DOF 仿真任务、匹配的单图 MAPPO、相同 PPO/奖励/环境/七个拓扑组/50% 正常工况锚点、共同 10M 预算和共同配对评估样本带下，DRTP 相对于 UTR 在正式五个训练种子的 F0、跨扰动均值和跨扰动最差端点上均表现出正的配对均值和中位数；同时存在碰撞率小幅上升、正式 seed2302 的正常工况退化，以及历史训练种子敏感性。

这支持以下受限表述：

> DRTP 在冻结任务中相对于均匀拓扑随机化显示出有前景的平均拓扑扰动鲁棒性收益，但训练结果对种子敏感。

这不支持以下表述：

- DRTP 稳定优于 UTR；
- DRTP 对所有外部基线优越；
- 在线自适应相对于任意固定非均匀权重已被证明必要；
- 具体权重变化已经因果导致某一确定策略机制；
- 对严格未见条件、通用拓扑、实飞或一般分布鲁棒优化作出保证。

## 3. 不需要重新训练的投稿收口顺序

1. 完成真实参考文献的正文编号替换，并逐条核对正文论断与引用账本。
2. 根据作者选定的中文期刊冻结摘要字数、图表规格、参考文献格式和中英文元数据要求。
3. 补充作者、单位、基金、利益冲突、通讯作者和数据/代码仓库信息。
4. 对图1–图7及图S1执行图号、图注、字体、单位、数据来源和终稿分辨率审计。
5. 运行中文稿 fail-closed 检查器，确认正式数值、seed 处理、历史结论和机器裁决字符串没有漂移。
6. 生成目标中文期刊格式的终稿 PDF，并进行逐页视觉检查。

## 4. 需要单独授权才可新增的内容

以下内容不属于当前无训练收口，任何一项都必须重新冻结合同后再决定：

- 固定非均匀权重对照；
- 新外部基线的重新实现或重训；
- 新训练种子、预算延长或新的 OOD 条件；
- 4/5 无人机、硬件在环或实飞实验；
- DRTP 稳定化新算法及其参数搜索。

它们可以提高论文上限，但不能被事后添加为解释当前正式结果的必要证据，也不能改变已有正式裁决或历史 `NO-GO`/`FAIL`。

## 5. 收口判据

在作者元数据、引用、图表和目标期刊格式补齐后，稿件即可进入中文投稿准备。除非目标期刊明确提出必须增加某项可比实验，否则不再因为“可能还有更高上限”而循环设计算法和重新训练。
