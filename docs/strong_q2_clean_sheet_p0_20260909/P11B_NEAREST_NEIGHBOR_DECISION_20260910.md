# P11-B 最近邻差异审查

## 判定

`P11B_CONDITIONAL_PASS_ACTIVE_REVELATION_ONLY / NO_TRAINING`

P11 原始表述中的以下内容已被 AURA 等相邻工作实质覆盖，必须删除其创新资格：

- 不确定任务能力需求；
- 专业机器人稀缺性；
- 未来任务机会成本；
- 需求确认存在延迟；
- 让专业机器人前摄靠近潜在支援任务；
- 任务价值、截止时间和联盟支援联合优化。

唯一保留的候选差异是：**需求揭示是团队主动选择且有成本的具身动作，而非外生随机时刻；侦察动作改变 belief 和后续联盟可行集。**

## 差异矩阵

| 维度 | AURA | 泛化动态 MRTA | P11 候选 |
|---|---|---|---|
| 任务能力需求不确定 | 是 | 部分 | 是 |
| 专业平台机会成本 | 是 | 部分 | 是，非创新来源 |
| 需求揭示 | 外生确认/可行性衰减 | 通常外生 | **主动具身侦察动作** |
| 信息动作可选择 | 否 | 通常否 | **是** |
| 信息动作消耗时空资源 | 未作为决策动作 | 通常否 | **是** |
| belief 更新影响联盟承诺 | 给定分布采样 | 部分 | **显式序贯耦合** |
| 主要方法 | 强耦合拍卖规划 | 规划或 RL | 尚未设计；必须 simple-first |

## 审稿风险

即使 P11-C 通过，审稿人仍可能将其描述为“AURA + active sensing”。因此正式冻结前必须证明：

1. 无主动侦察时，AURA-style 前摄定位不能恢复主要 oracle gap；
2. 信息动作存在任务级空间语义，而非点击查询隐藏标签；
3. 侦察者选择会占用原本可执行任务的 UAV，并产生可度量机会成本；
4. 简单 one-step VoI 若已经足够，则使用简单方法，不包装复杂 MARL；
5. 若必须依靠复杂网络才能赢，但机制消融无法识别，则停止。

## 下一阶段 P11-C

建立不含候选算法的最小具身任务：侦察 UAV 必须飞入观测区域并停留，才以受控噪声揭示任务能力需求；专业 UAV 同时面对当前不确定任务与未来确定任务。先运行脚本策略和动态规划 oracle，冻结以下门：

- baseline 可学习但不饱和；
- always-inspect、always-commit、AURA-style proximity、myopic VoI 均至少留下可测 oracle gap；
- oracle 在 inspect/commit/reserve 三类动作上均有非平凡占比；
- 相同几何下 belief 或 deadline 改变会改变最优决策；
- 任务主要收益不能来自侦察奖励；
- 若以上不成立，P11 关闭。
