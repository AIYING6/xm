# 公开基准主线：唯一候选的三重筛选与冻结门

## 结论

本文件冻结**唯一允许进入下一步零训练审计的候选**，但不授权方法实现或长训练：

> **在具有异构飞行速度、任务收益与时间窗的公开多 UAV 任务分配基准中，研究“执行时长不确定性下、何时应保留可重分配能力，而非立即填满当前高收益任务”的去中心化协同决策。**

工作名：**ECR-MRTA（Execution-Contingent Reallocation for Multi-Robot Task Allocation）**。

它的基础资产是公开的 Extended Team Orienteering Problem 多 UAV 任务分配基准，而不是再造一个自定义玩具环境。该基准明确给出异构飞行速度、任务收益、执行时间与任务时限，并提供可替换的 `step` 接口；现有仓库也承认 RL 部分尚未提供完整示例。[公开基准与接口说明](https://github.com/robin-shaun/Multi-UAV-Task-Assignment-Benchmark)

**注意：**这不是“动态任务分配”或“带不确定性的 MARL”这一宽泛选题。该宽泛表述已被近期多机器人/多 UAV 工作覆盖，不能作为论文创新点。例如，RL-TAPU 已讨论异步任务完成和不确定环境下的实时分配；2026 年的 UAV 工作也已提出动态目标分配或事件触发的任务重分配。[RL-TAPU](https://doi.org/10.1111/mice.13535)；[动态 UAV 目标分配](https://doi.org/10.1109/JIOT.2026.3686066)；[事件触发重分配](https://doi.org/10.1016/j.aei.2026.105107)。

因此，本候选只在下面六门全部通过时才成为新主线。

## 三重筛选

| 维度 | 已知事实 | 通过条件 | 当前状态 |
|---|---|---|---|
| 文献 | 静态任务分配、动态重分配、执行不确定性与 MARL 都已有丰富工作 | 能清楚证明“**保留可重分配能力的决策语义**”未被既有机制直接覆盖，且不是换名的风险敏感、重规划或合同网 | 待审计 |
| 可识别性 | 公开基准包含异构速度、收益、时间与预算，却是静态实例 | 在不改变策略输入规模或奖励口径的前提下，存在至少三类实例：立即承诺最优、保留能力最优、事后重分配最优；没有单一固定规则同时最优 | 待审计 |
| 成本 | 基准轻量，原始实现可在 CPU 多核执行，且含比较结果 | 先完成规则求解器、随机/贪心/MAPPO 可学习性短试；任一失败即停止，不进入 100M 级训练 | 待审计 |

## 唯一可检验机制

### 问题缺口

任务执行时长并非瞬时且会偏离计划时，过早把所有 UAV 承诺给当前高收益任务，可能使系统在后续高价值任务出现、早期任务延期或可用 UAV 变化时失去重分配能力。反过来，过度保留又会造成即时任务损失。

论文要检验的不是“RL 能否做任务分配”，而是：

> **对每架 UAV 的未来可用性进行显式、可学习的承诺管理，是否能在异构任务执行不确定性下改善完成收益—逾期风险折中？**

### 唯一干预（尚未实现）

候选方法只允许新增一个可审计的决策变量：

\[
c_i \in \{\text{commit},\ \text{reserve},\ \text{release-on-event}\},
\]

其中 `reserve` 不产生隐藏信息，也不更改动力学、任务收益、PPO、网络容量或评价任务；它只是使策略在当前分配时显式表达“为后续事件保留此 UAV 的重分配资格”。事件到达、任务时长分布及信息可见性必须对所有方法一致。

对照必须包括：

1. 同一 MAPPO 骨干的即时承诺策略；
2. 同一 MAPPO 骨干的事件触发重分配策略，但没有 `reserve` 语义；
3. 候选方法；
4. 不学习的贪心和滚动重规划参考。

若 `reserve` 仅等价于延迟/空闲，或用现有事件重规划即可无损复制，则候选停止。

## 预先冻结的六道门

| 门 | 零/低训练证据 | 失败即停止的原因 |
|---|---|---|
| G0：公开资产 | 原始基准可复现、许可证明确、接口可接入本仓库且不复制现有论文环境 | 无公共任务底座，投稿可信度与复现性不足 |
| G1：反例 | 穷举小实例证明立即承诺、保留、事件重分配至少各有严格最优区间 | 没有真实决策张力，机制只是人为设计偏好 |
| G2：可识别性 | 证明 `reserve` 与等待/空闲/普通重规划在观测、动作后果和评价端点上可区分 | 不能将任何收益归因于候选机制 |
| G3：文献新颖性 | 对最接近的异步分配、执行不确定性、合同网、风险敏感分配逐篇建立“已有内容—仍缺内容”矩阵 | 只是已有机制的改名组合 |
| G4：学习性 | 3 个固定 seed 的短预算中，基础 MAPPO 优于随机、未饱和且至少两种行为模式都出现 | 环境不可学习或一条固定规则塌缩即可解决 |
| G5：成本 | 根据短试实测单 seed 每百万步时间与显存，给出正式预算上限和停止点 | 不能在可承受预算内完成可信比较 |

只有 `G0–G5 = PASS`，才允许写正式训练合同。任何一个 `STOP` 都永久关闭本候选；不以调奖励、加 seed、延长训练、重命名机制的方式补救。

## 不允许的叙事与操作

- 不把任务时长随机化本身称为创新。
- 不把贪心分配、重规划或合同网换一个名后作为新方法。
- 不在 G4 之前实现复杂网络、辅助损失、图注意力或新奖励。
- 不用历史 DRTP、P41、P40 或任何旧实验的结果支持本候选。
- 不开展涉及武器目标选择、攻击分配或伤害优化的场景；任务只限于应急物资、巡检或服务调度。

## 当前下一步（唯一）

执行 G0–G3：公开资产许可证/接口检查、最小离散反例、`reserve` 与普通等待/重规划的可区分性审计、以及 8–12 篇最近邻论文的机制矩阵。该步骤**不训练、不改主仓库环境、不定方法名**。

G0–G3 未全部通过前，禁止启动 G4 或云端训练。
