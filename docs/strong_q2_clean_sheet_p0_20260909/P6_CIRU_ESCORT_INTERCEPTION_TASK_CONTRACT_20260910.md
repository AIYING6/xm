# P6 CIRU 护航—拦截任务：一次性重构合同

日期：2026-09-10  
状态：`DESIGN_FROZEN / NO LEARNING AUTHORIZED`

## 1. 为什么重构任务，而不是修改门槛

旧 OSTA 实例已经验证“我方响应会改变对手轨迹”，但 R1–R4 红方策略面对临时蓝方响应库时均由 R3 占优，因而不存在需要根据历史选择不同响应的决策问题。继续开发反事实选择器只会把模型复杂度叠加在一个不存在的选择缺口上。

本次只允许一次任务实例化重构。科学问题仍是 CIRU 的反事实响应效用估计，但任务改为具有现实目标冲突的多无人机护航—拦截：蓝方保护高价值无人机穿越威胁区，红方以不同团队意图实施突防或消耗。蓝方必须从有限交互历史中选择团队防御响应。

## 2. 任务与信息边界

蓝方由一架受保护任务机和两架防御机组成；红方由两架攻击机和一架支援/诱饵机组成。蓝方成功定义为受保护任务机存活并到达出口走廊，而不是简单获得更高击落数。红方意图包括集中突击、分轴饱和、诱饵侧击和先消耗防御机。

蓝方只能看到截至决策时刻的双方可观测运动状态、存活状态和时间，不可看到红方意图标签、未来动作或任何反事实分支结果。所有候选响应共享相同动力学、传感范围、武器规则、奖励和预算。方法只能改变决策时选择哪一个冻结团队响应。

## 3. 为什么该构造不是人为收益矩阵

四种蓝方响应分别对应近距伴随、前出拦截、分区屏障和预备队反击。它们不绑定红方标签，也不获得响应专属奖励。胜负与效用必须由统一的运动、拦截、资产存活和航路进展规则自然产生。禁止直接指定“某意图被某响应克制”的 payoff 表。

如果统一物理规则不能自然产生至少三种不同最佳响应和可观的 oracle headroom，本选题关闭；不能通过修改奖励或挑选场景制造互补性。

## 4. 反事实识别结构

决策时刻冻结为回合 20%（第 48/240 步）。对于同一初始状态、随机流和决策前历史，在该时刻复制环境运行态，并分别执行四个候选响应。由此得到真实的配对反事实标签：

\[
Q_k(h_{48}) = G(\text{clone}(s_{48}), B_k), \quad k=1,\ldots,4.
\]

该标签只用于离线训练和评价反事实效用模型，不在在线策略输入中泄露。训练、验证和测试按初始场景及红方策略家族分割，禁止同一反事实分支跨集合泄漏。

## 5. 三道训练前硬门

### Z1：交互诱导偏移

在保持红方意图和初始场景相同的条件下，改变蓝方决策前交互策略，应使红方前缀轨迹产生可测差异。至少 50% 案例超过冻结距离阈值，且案例距离中位数不低于 0.05。

### Z2：行为混叠但最优响应不同

至少两对红方意图必须同时满足：前缀行为距离不超过 0.15、最佳响应不同、最佳响应相对第二名的归一化效用余量不低于 0.10。否则 history-only 与反事实建模之间没有足够的可检验区分。

### Z3：响应互补性与 oracle 余量

四类意图中至少出现三种不同的最佳响应；任一响应成为最佳的比例不得超过 50%；逐案例 oracle selector 相对最佳静态响应的归一化增益至少为 0.10。

任何一道门失败即关闭 CIRU，不训练模型、不调门槛、不增加“更容易通过”的隐藏奖励。

## 6. 通过后才允许的方法实验

若 Z1–Z3 全部通过，下一阶段才实现：history-only utility predictor、response-conditioned factual predictor、CIRU counterfactual predictor，以及去掉 support-aware uncertainty 的消融。主要指标为 response regret、反事实排序准确率和任务成功率；训练种子是独立统计单位，反事实分支和 episode 不是独立重复。

## 7. 论文价值与边界

该任务把论文问题从“识别对手属于哪一类”推进为“当前历史由双方互动共同生成时，如何估计未执行团队响应的效用”。若通过地基门，CIRU 的核心贡献可以由反事实估计误差、响应遗憾和支持度分层风险直接检验；若不通过，项目在投入训练前终止，不以 UAV 场景包装一个没有决策必要性的选择器。
