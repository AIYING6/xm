# A0 Q0：互补视角几何资格验证

## 结论

`A0_Q0_PASS`。在零训练、零环境 rollout 的线性高斯 bearing-only 几何验证中，互补视角产生了可复算的联合估计优势，因此 A0 可以进入“最小动态环境 + 普通 MAPPO 可学习性”阶段。

## 受控构造

目标位于 `(0, 0)`；一架 UAV 固定在 `(-5, 0)`；另一架 UAV 从 `(-4, -3.5)` 出发，可等代价移动到：

- 聚集端点 `(-2, 0)`；
- 互补端点 `(0, -3)`。

两条机动距离都为 `4.0311`。聚集端点的单机 bearing Fisher information trace 更高（`1.25` 对 `0.5556`），因此任何只按单机即时信息选择的规则会偏向聚集端点。

但在相同先验和测量噪声下，固定视角与互补视角组成的联合后验 `log(det(P))` 为 `0.2231`，显著低于固定视角与聚集视角的 `1.3011`。较低 log-determinant 对应更小的联合状态不确定性。

## 证据边界

Q0 只说明**等机动代价下，单机即时信息偏好与团队联合可观测性偏好可以相反**。它尚未证明：

- 动态目标任务可学习；
- MAPPO 能形成互补策略；
- OC-MAPPO 比任何基线更优；
- 该二维测量模型代表真实飞行系统。

下一步的唯一授权是建立最小动态环境并进行普通 MAPPO 的短预算学习门；不实现 OC-MAPPO。
