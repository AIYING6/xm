# C1：潜在能力漂移下的开放团队协同——研究合同

**状态：** 候选；尚未授权训练，尚未形成方法主张。  
**日期：** 2026-09-11  
**目的：** 用公开多智能体基准作为主要证据、UAV 连续协同任务作为应用证据，检验该问题能否支撑一篇独立的算法论文。

## 1. 研究问题（暂定）

在开放异构团队中，智能体的**有效能力**并不总是可直接观测：能力可在任务执行中通过进度、失败或队友行为逐步显露，并可能随运行条件发生改变。每个智能体只能访问合法的局部历史，因而需要在协作任务中同时处理：

1. 当前任务推进；
2. 对队友能力状态的在线推断；
3. 能力推断变化后对协同动作的去中心化调整。

本文不将“任务分配”“资源预留”“通信故障”或“成员离开”单独描述为创新。只有当潜在能力状态会使两个合法历史不可区分、且不同后续协同决策具有可验证的任务价值时，才继续该问题线。

## 2. 与已知工作的区别必须满足的条件

下列已有方向均不能被换名重复：

- 已知或随时可读出的异构能力下的任务分配；
- 不确定任务需求下的邻近待命／资源预留；
- 已知团队组成下的动态任务调度；
- 仅改变团队人数的开放团队策略；
- 以全局教练或中央调度器作为执行期信息来源的方法。

候选方法若存在，必须仅利用执行期允许的局部历史；其唯一机制应当是**能力后验如何改变去中心化协同行为**，而非增加隐藏全局信息、规则化调度或奖励塑形。

## 3. 两层证据设计

### 主层：公开基准

选择支持局部观测、异质角色与任务开放性的公开多智能体环境。主实验须使用公开环境、公开接口和可复现 baseline；不得将自建 UAV 环境作为方法有效性的唯一来源。

### 应用层：UAV 协同

UAV 环境只验证同一机制在连续控制、续航/载荷差异或任务进度可观测但能力隐状态不可直接读取时是否仍有价值。它不能代替公开基准的主要因果证据。

## 4. 训练前四道硬门

| 门 | 必须观察到的事实 | 否决条件 |
|---|---|---|
| G0 信息价值 | 至少存在一对对某执行者合法历史相同、但潜在能力不同且最优协同后续动作不同的状态 | 仅有状态标签不同或读取隐藏能力才产生差异 |
| G1 基线可学性 | 标准 MAPPO/强公开 baseline 可稳定完成非平凡比例任务，但未出现全面饱和 | 基线接近零或全面饱和 |
| G2 行为承重 | 移除能力后验、打乱后验或提供真实能力时，均能产生与假设一致且可量化的决策变化 | 后验不改变动作，或简单规则等价 |
| G3 外部一致性 | 同一干预至少在一个公开基准与一个 UAV 应用中给出方向一致的任务/可靠性证据 | 仅在自建 UAV 环境有效 |

任一门失败即停止该候选；不得通过奖励、阈值、种子或训练预算扫描来挽救。

## 5. 预注册消融结构

若 G0--G2 通过，比较只能包括：

1. 匹配 MAPPO/公共强 baseline；
2. 完整的能力后验条件协同；
3. 后验打乱对照（保留网络容量与训练流程）；
4. 真值能力上界（仅作诊断，不可作为公平执行期基线）。

必须分别报告任务完成、任务延迟、失败/约束违规以及能力校准。训练 seed 才是独立统计单位。

## 6. 当前结论边界

该合同不是论文题目冻结，不证明新颖性，也不授权训练。它只将下一步压缩为一次公开基准的 G0--G2 零训练/短基线审计：如果该审计通过，才开始方法设计；否则结束 C1。
