# 历史候选的可复用证据与下一题设计约束

**目的：** 将已停止候选转化为下一条主线的可验证设计约束。本文不重启任何已停止方法，不把 pilot 或历史结果包装为正式论文证据，也不授权训练。

## 1. 可保留的正面资产

| 已获事实 | 证据文件 | 对新课题的实际价值 | 不能外推为 |
|---|---|---|---|
| 身体朝向同时限制目标感知与定向链路，存在可枚举的联合可行性冲突 | `P17_COUPLED_GAIN_EXISTENCE_20260910.md` | 可作为具身协同任务的物理约束，而非人为拼接的奖励冲突 | 多智能体方法已经有效 |
| 在充分观测的单机原型中，学习策略超过固定规则并接近修正后的 DP 上界 | `P18_ATTITUDE_COUPLED_LEARNING_20260910.md` | 说明该物理冲突存在一个“可学习、未饱和”的基础区间 | 任何新机制优于 PPO，或任务已足以成文 |
| A/B 等历史 DRTP 资产与新线分离 | `P0H_DECISION_AND_P1_CONTRACT.md` | 已有训练、审计、seed 级汇总与固定端点基础设施可复用 | 可把 DRTP 数字作为下一题的证据 |

## 2. 必须继承的失败约束

| 失败模式 | 证据文件 | 下一题的强制设计规则 |
|---|---|---|
| 任务无真实选择题：主动探测/校准不改变最优任务决策 | P3B 的 `P3B_CALIBRATION_STOP` 汇总 | 在训练前用解析枚举或 DP 证明至少两个合法状态下的最优联合动作不同；否则不训练 |
| 安全降级支配一切：策略塌缩为 always-defer / fallback | `P2_COMPLETED_PILOT_AUDIT.md` | 必须预先证明 commit、wait、reconfigure 至少各在一个非零测度上下文中严格最优；并把三类选择频率设为辅助端点 |
| 固定规则能击败学习策略 | `P19_TEAM_COUPLED_20260910.md` 与 `P20_MOVING_TEAM_20260910.md` | 在选题前枚举同计算预算的周期、阈值、贪心、上界或小型规划器；若规则已接近上界，则不把该任务用作算法主证据 |
| 任务全局不可学：全条件 timeout、奖励无中间信用 | 6-UAV V3 UTR pilot 与只读诊断 | 首先验证名义条件在多 seed 下可学、故障条件不饱和；奖励或可验证的中间任务进度必须在冻结环境语义中自然存在，不能事后为方法加分 |
| 信息推断、对抗修复、伙伴泛化等“新机制”与近邻文献直接重合 | `STRONG_Q2_PROBLEM_SPACE_SCREEN_20260911.md` | 新方法必须改变一个可写成状态/动作/约束的决策对象，而非换 encoder、采样权重、辅助损失或训练队列 |

## 3. 下一题的最小结构（不是方法方案）

后续题目只允许从以下结构出发：

1. **物理承载：** 保留已证实的“机体动作同时塑造感知与链路可达性”约束；
2. **多人耦合：** 至少两架 UAV 的局部行动必须共同决定一条信息—服务链是否可完成，单机 PPO 的成功不能代替该条件；
3. **非支配选择：** 在不同可观察上下文中，至少两种任务层选择（例如维持服务、重构链、延迟交接）交替严格最优；
4. **唯一干预：** 候选方法改变该选择的表示、优化对象或约束处理；物理、观测、低层控制、奖励、预算、对照容量必须保持一致；
5. **三个证据层：** 零训练的可识别性反例，短程的可学习/非饱和门，正式的多 seed 主比较与机制消融。

这一定义故意不包含“通信故障”“采样”“belief”“对手建模”或具体算法名；这些均可能把课题拉回已排除的近义机制。

## 4. 训练前立项门（唯一入口）

任何下一候选必须一次性提交并通过以下五项，不能逐项失败后修补：

| 门 | 冻结前必须给出的事实 |
|---|---|
| D1 选择存在性 | 枚举/DP 证实任务层动作在至少两个合法上下文中互不支配 |
| D2 基线区间 | 容量匹配的 PPO/GRU 基线可学习但不饱和；规则基线无法覆盖同一冲突区间 |
| D3 机制差异 | 与最接近三篇方法的输入、决策对象、损失/更新和执行语义逐项不同 |
| D4 因果消融 | 至少一个只移除核心对象、但保留参数量和训练预算的对照；预先定义结果何时不纳入论文 |
| D5 证据闭环 | 主指标、可靠性指标、失败边界、统计单位、独立验证和计算成本在训练前冻结 |

**执行纪律：** D1--D5 不是五次迭代审计，而是一份完整的立项说明书。缺任一项即不立项；全部具备后，先跑一次受限 pilot，再决定是否投入正式训练。

## 5. 当前推荐

历史资产中，P18 的“姿态—感知—链路联合可行性”是唯一已被实测为**存在物理冲突且基线可学习**的底座。它不是已选题，也不应直接扩写为“姿态耦合 MAPPO”。下一轮的工作应仅围绕该底座定义一个多人、部分可观测、存在非支配任务选择的新决策问题，并一次性完成 D1--D5；不能回到 P20 的移动队形任务，不能修复已经停止的 P2/P3B，也不能用 DRTP 结果替代新线证据。
