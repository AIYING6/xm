# P41 v2 T4 UTR 可学习性：停止

## 冻结结论

`P41_V2_T4_STOP`。不授权在 P41 v2 上提出、实现或训练任何新机制。

## 已完成的冻结试验

- 统一训练暴露（UTR），新训练种子 `95101--95103`；
- 每 seed 512 updates、16 并行环境、9 步回合；
- 训练、验证与最终 tape 分离；
- 三个 endpoint 均生成后才打开最终 360-episode tape；
- 使用同一最终 tape 上的随机合法动作参考与 audit oracle；
- 不存在 checkpoint promotion、提前停止、seed replacement、DRTP、PLR、课程学习或奖励后调。

结果记录：
`results/development/p41_v2_utr_t4_20260911/diagnostics/P41_V2_T4_RESULT.json`。

## 门槛结果

| 冻结判据 | 结果 | 含义 |
| --- | --- | --- |
| UTR 超过随机合法动作 | 通过，3/3 seed | 任务并非不可学习或纯随机噪声 |
| 各压力族非零服务价值 | 失败，仅 1/3 seed | 两个 endpoint 在至少一个压力族完全失效 |
| 未达到 oracle 饱和 | 通过 | 任务仍留有提升空间 |
| 两个服务站点与中继重构均被使用 | 失败，0/3 seed | 学得策略退化为单一行为模式 |

三个 seed 的最终平均服务价值分别为约 7.67、4.97、7.67，均高于匹配随机参考约 1.09、0.88、1.13；但这不能抵消压力族覆盖与行为覆盖的失败。

## 诊断解释边界

该结果表明，在当前 v2 的奖励、观测与一次承诺构造下，短 UTR-PPO 能学到有价值行为，却在不同 seed 间收敛到互相排斥的固定策略：两个 seed 偏向未来站点与频繁重构，另一个 seed 偏向当前站点且不重构。它不能形成兼顾三类压力情境的稳定决策规则。

这不能证明任何更复杂的机制无效，也不能证明任务本身没有决策张力；但它确实否定了一个关键前提：**不能在该 v2 任务上把“UTR 学到的失败模式”视为可靠、可复现的新方法缺口。**

## 禁止的后续动作

- 不增加 updates、seed 或 scenario 数以挽回结果；
- 不调奖励、预测概率、截止期或链路时机；
- 不向 actor 添加未来真值、全局状态或专家提示；
- 不将单一优秀 seed 作为候选机制设计依据；
- 不把本次 T4 结果写入论文正向证据。

P41 v2 保留为任务构造与失败模式的内部记录。新的课题筛选必须回到不同的任务基础，而不是对 P41 进行 v3/v4 参数迭代。
