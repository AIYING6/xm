# P5 强二区新课题：开放范围零训练选题审查

## 1. 范围重置

本轮不以通信、拓扑、DRTP、CEC-MAPPO 或现有仿真资产为默认起点，也不把代码复用率作为
选题标准。通信故障只是一类可能的外生事件；如果安全、任务组合、团队变化、资源约束或
其他问题能形成更强的科学缺口，应优先选择更强问题。

筛选顺序固定为：**问题价值 → 最近邻差异 → 因果可识别性 → 机制必要性 → 实验闭环 →
工程与算力成本**。在前五项没有通过前，不因“容易实现”而启动训练。

## 2. 本轮文献审查覆盖

本轮以 PMLR、OpenReview、arXiv、IEEE、AAAI 和出版商原文页面为主要来源，覆盖：开放团队与
能力泛化、动态任务分配、组合泛化、风险敏感与安全 MARL、反事实损害、因果责任、故障后恢复、
稀疏信用分配以及异步通信。当前判断是方向筛选，不是完整新颖性证明。

主要碰撞包括：

- 动态队伍与零样本团队泛化已有 COPA、开放临时协作、CAMA 以及能力感知共享超网络等直接工作；
- CVaR、风险分解、拉格朗日约束和安全策略改进已形成成熟的安全 MARL 方法族；
- 通信时机、延迟等待、反事实消息信用和异步图表示均已有直接近邻；
- 故障后连通恢复、弹性任务分配和一般 Recovery RL 不能作为新的宽泛创新点；
- 单智能体“反事实损害”已经明确区分不可避免违规与策略额外造成的损害，但其作者将多智能体
  扩展列为未来工作；多智能体责任归因已有形式化研究，但尚不能据此认定一个面向协作控制的
  可训练责任约束具有新颖性。

## 4. 首选候选 A：团队可避免损害责任学习

### 4.1 科学问题

协作任务中的碰撞、超时、能量耗尽或任务失效往往由一段联合决策共同形成。标准共享成本把
最终违规同时施加给所有成员；逐智能体成本则可能忽略联合行为的互补性。更关键的是，当外生
扰动已经使某些损失不可避免时，传统约束仍会惩罚策略无法阻止的部分。这混合了两类对象：

1. 给定当时信息与动力学后不可避免的基线损失；
2. 当前联合策略相对可行反事实额外造成的可避免损失。

候选问题为：

> 能否在部分可观测的异构多智能体任务中，定义并学习团队级可避免损害及其反事实责任，
> 只约束由联合决策额外造成的损害，同时维持任务效用？

这一问题不依赖通信故障。可用扰动包括执行器退化、突发禁飞区、剩余能量失配、目标变化、
成员失效或感知不确定性；最终选哪一种由 Q0 的可识别性决定。

### 4.2 暂定数学对象

对联合历史 `h_t`、联合动作 `a_t`、外生变量 `u` 和满足同一信息边界的安全参考决策
`a_t^0`，定义短期或有限时域损害差：

`H_t = [C(tau(h_t, a_t, u)) - C(tau(h_t, a_t^0, u))]_+`。

团队责任向量 `rho_t` 必须满足至少三项性质：

- 效率：成员责任之和与可避免损害一致；
- 空参与者：反事实替换某成员动作不改变损害时，其责任为零；
- 信息合法性：执行期决策不能读取部署时不可获得的全局变量。

候选方法不是“再加一个安全惩罚”，而是用责任分解得到成员/联合动作相关的约束优势，再与
一个受控的 MAPPO 约束更新结合。上述定义只是 Q0 工作假设，尚未冻结。

### 4.3 必须可证伪的预测

- 在总违规相同的轨迹对中，方法应区分外生不可避免损失与策略额外造成的损失；
- 在一个成员对结果没有边际影响的构造中，其责任必须接近零，而共享惩罚不会；
- 与团队总成本约束相比，责任约束应在相同安全水平下减少无效保守行为；
- 去掉反事实基线后应退化为普通成本归因；去掉责任分解后应退化为团队共享约束；
- 若参考决策不可行、反事实不可辨识或估计误差不可控，则该方向必须停止，不能靠训练结果补救。

### 4.4 最小受控消融

| 方法 | 团队安全约束 | 不可避免损害基线 | 多智能体责任分解 |
|---|---:|---:|---:|
| MAPPO | 否 | 否 | 否 |
| MAPPO-Lagrangian | 是 | 否 | 否 |
| Counterfactual-team-cost | 是 | 是 | 否 |
| 完整候选 | 是 | 是 | 是 |

这组实验分别检验：安全约束本身、反事实“可避免性”以及成员责任分解是否各自带来可识别影响。
外部结构不同的方法只能用于性能定位，不能替代这组因果对照。

## 5. 第二候选 B：任务级协同可恢复性

P4 的“协同可恢复性”保留，但不再默认围绕通信。其对象改写为外生扰动发生前，联合物理状态、
资源和剩余时间中保留的可行任务延拓集合。只有当它能与 viability、安全余量和 contingency
planning 明确区分，且能构造“相同即时风险、不同未来恢复能力”的状态对时才继续。

## 6. 训练前硬门槛

P5 当前只授权 A、B 两条零训练 Q0 审查，禁止实现学习器和启动训练。

候选 A 必须全部通过：

1. **全文最近邻门**：审计 counterfactual harm、safe MARL、difference rewards、COMA/反事实
   信用、Shapley responsibility、actual causality 与 multi-agent constrained control；
2. **对象门**：冻结损害、默认策略、外生变量和责任的数学定义；
3. **可辨识门**：说明同一观测数据下反事实量何时可识别，哪些假设不可检验；
4. **非退化门**：解析构造普通共享约束失败而责任约束正确的最小博弈；
5. **估计门**：零训练枚举验证责任效率、空参与者和误差界；
6. **任务门**：短任务中基线可学习、不饱和，且可避免与不可避免损害同时出现；
7. **消融门**：四个方法只改变声明机制，架构、预算、信息与优化器可匹配；
8. **论文门**：在不写 UAV 应用词的情况下，仍能用一句话说明新的科学机制。

候选 B 必须通过 P4 已定义的最近邻、数学定义、非退化反例、枚举预测效度和受控消融门。

## 7. 当前决定与下一步

当前状态为 `OPEN_SCOPE_SHORTLISTED`，不是方法冻结，也不是训练授权。

下一步只做两个并行零训练任务：

- **P5-A-Q0**：完成团队可避免损害最近邻差异矩阵与最小解析博弈；
- **P5-B-Q0**：完成任务级可恢复性最近邻全文审计与非通信反例。

两者用同一评分表比较。只有一个候选能进入 Q1 任务设计；若二者均不能形成清晰的“最近邻没有
解决什么 + 本方法新增什么 + 哪个消融能识别”，则继续开放搜索，而不是降低门槛。
