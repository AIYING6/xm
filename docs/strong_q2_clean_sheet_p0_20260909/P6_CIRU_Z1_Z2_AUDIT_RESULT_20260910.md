# P6 CIRU：Z1–Z2 零训练地基审计结果

日期：2026-09-10  
结论：`CURRENT_OSTA_INSTANTIATION_FAILED_Z2 / NO_TRAINING_AUTHORIZED`

## 审计范围

在 OSTA 冻结的 `3v3_eval_v2` 场景带上，取前 32 个相同初始场景，将 R1–R4 分别作为蓝方候选响应与红方策略进行 4×4 交叉执行，共完成 512 条确定性 rollout。审计不训练网络、不更新参数，PPO 更新数为 0。阈值和样本数在运行前冻结于 `configs/p6_ciru_z1_z2_readonly_audit_20260910.json`。

## Z1：响应诱导偏移

Z1 通过。128 个“红方策略×初始场景”案例中，99.22% 的案例在切换蓝方响应后产生超过冻结阈值的红方前缀行为差异；案例内最大行为距离的中位数为 0.2030，高于 0.02 的最低门槛。

这说明在当前交互系统中，对手轨迹不是与我方响应无关的外生样本。该结果支持 CIRU 所研究的“响应诱导轨迹偏移”前提，但不能证明反事实学习方法有效。

## Z2：行为混叠与最佳响应分歧

Z2 失败。R1–R4 的前缀行为距离均低于 0.055，存在明显相似性，但四种红方策略的最佳蓝方响应全部是 R3。各自相对第二名的平均回报优势分别为 1.4812、2.3909、1.7734 和 1.7737。因此 6 个红方策略对中，没有任何一对同时满足“前缀相似、最佳响应不同、最佳响应余量充分”。

失败原因不是缺少交互诱导偏移，而是当前临时蓝方响应库缺乏决策互补性：R3 对所有已测红方策略形成统一优势。当前资产中也不存在已经成熟训练并通过 cross-play 的 B1–B4 specialist checkpoint，不能用尚未存在的响应专门化结果替代 Z2。

## 决策

1. 不启动 CIRU 模型训练；
2. 不移动阈值，不从 512 条 rollout 中挑选有利场景；
3. 不把 R1–R4 对称复用继续当作正式响应库；
4. 保留 CIRU 科学问题，因为 Z1 已验证其关键交互前提；
5. 仅允许一次任务实例化重构：构造具有可解释目标冲突和互补响应的多无人机护航—拦截任务，并在任何学习训练前重新通过 Z1、Z2 和 Z3；若仍失败，关闭 CIRU。
