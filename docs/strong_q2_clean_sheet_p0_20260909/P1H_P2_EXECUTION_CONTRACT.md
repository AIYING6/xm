# P1H：P2 有界性能 pilot 执行合同

## 冻结问题

P2 只检验一个问题：在相同两阶段 UAV 任务、合法局部历史、PPO 目标、训练预算和参数量下，显式对信息集内任务承诺价值作保守决策，是否比容量匹配的直接循环策略减少单边承诺，同时保持任务价值。

该 pilot 不使用旧 DRTP 结果，不把通信恢复、隐藏真值或训练样本重加权作为候选方法输入。

## 设计

- 方法：`information_set_commitment` 与 `capacity_and_risk_matched_recurrent`。
- 独立统计单位：训练 seed。
- 冻结 seeds：98101、98102、98103。
- 每条轨迹：62,500 episodes × 16 物理步 = 1,000,000 物理步。
- 总上限：6 条轨迹、6,000,000 物理步，低于 P1D 的 15M 上限。
- 评价：固定最终 checkpoint；每 seed 使用同一 300-episode tape；禁止按回报选 checkpoint。
- 执行顺序：preflight → 六条训练 → 六个固定终点评价 → seed 级汇总。

## 继续门

只有同时满足以下条件，P2 才给出 `P2_PILOT_CONTINUE`：

1. 容量匹配基线的平均任务价值高于常数 defer 基线 2.9333，排除任务整体不可学习；
2. 至少 2/3 seed 同时满足：候选单边承诺率至少降低 0.05，任务价值差不低于 -0.5，高可靠与低可靠上下文的 leader 承诺率差至少 0.20，fallback 增量不超过 0.20，且碰撞和约束违规不高于基线。

任一失败只停止本候选进入扩大实验，不自动修改超参数、不补 seed、不发明新模块。

## 证据边界

P2 是有界性能 pilot，不是正式论文确认性实验。通过表示候选值得进入后续正式任务设计与独立验证；停止表示当前冻结实现没有证明其任务价值，不等于主动承诺机制在一般 MARL 场景中无效。
