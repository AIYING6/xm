## 为什么不能代替 P3-Q1

P2 是 16 物理步、两阶段的简化决策核，任务值由简化 episode spec 决定。审计数据中，三个
循环基线虽然在所有上下文都执行相同的 100% `defer`，其 low/middle/high 平均任务值仍分别为
1.6、2.8、4.4。这种结果适合用于筛查抽象信息结构，却不能作为“动作经 3DOF 轨迹导致任务
结果”的投稿级证据。

P3 已改为 8 个决策 epoch、64 个物理步、离散承诺与连续制导联合控制，并由进入时序、末端
队形、撤离趋势、碰撞和约束事件重建端点。因此 P2 的完成不能免除 P3-Q1 的任务可学习性
验证。

## 正确归类

该结果归类为：`COMPLETE_NEGATIVE_PRECURSOR_PILOT`。

它能够支持以下判断：旧两阶段构造和对应目标未产生非退化条件化策略，按预设门停止是正确
的；这为转向 P3 多阶段轨迹任务提供了工程与研究动机。

它不能支持以下主张：信息集承诺方法普遍无效、P3 不可学习、P3 候选方法没有优势，或任何
