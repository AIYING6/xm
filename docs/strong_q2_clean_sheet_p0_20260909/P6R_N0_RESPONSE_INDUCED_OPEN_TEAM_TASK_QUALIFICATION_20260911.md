# P6R N0：响应诱导开放团队任务资格审计

## 目的

P6R 不复用旧 OSTA/CIRU 的结论，也不以“识别对手类型后从策略库选择动作”作为创新。该阶段只检验一个更窄的前提：在**相同的被动观测前缀**下，友方可观测的队形承诺会诱导隐藏对手产生不同后续反应，且不同对手规则对应不同的最优友方响应。

如果这一前提不成立，则“响应诱导效用排序”没有可识别对象，不应命名方法、更不应启动训练。

## 最小任务

采用非武器化的双通道服务护航竞争：友方为两个服务通道分配两架护航 UAV；对手在观察到该空间分配后，为相同通道调度阻断资源。两方在决策前经历相同的中性集结前缀；隐藏的是对手**反应规则**，而不是通过观测泄漏的标签。友方的四种可执行响应分别为左侧承诺、右侧承诺、均衡覆盖和可见的左侧佯动后转向右侧。

所有响应共享同一资源动力学、服务计分和转向成本。对手规则仅读取已观察到的队形承诺和可见转向，不读取响应名称。

## 冻结门

N0 只在下列条件同时满足时通过：

1. 至少三条对手反应规则拥有不同且有间隔的唯一最佳友方响应；
2. 三条对手规则的被动前缀相同；
3. 至少三分之二对手规则的后续分配会随友方可观测响应改变；
4. 不存在跨全部规则都最佳的通用响应。

## 解释边界

此审计是为避免“先训练再发现不存在决策冲突”而设的任务资格测试。即使通过，也**不证明**连续 UAV 任务可实现、MAPPO 可学习、P6R 方法有效或研究问题具备发表新颖性。

下一步只能是 N0.4：以相同信息边界和相同计分，在连续 UAV 动力学中重现上述响应专门化与被动前缀混叠；不得以脚本效用表替代。
