## 首选候选 A：协同可恢复性塑造

### 科学问题

现有鲁棒训练通常在故障出现后学习维持回报，连接恢复方法则直接恢复通信图。二者都未必要求
故障前策略保留“任务层面的接续选择”。在不可预测的链路或成员损失下，名义最优行为可能
消耗关键 UAV 的位置、能量、可见性或时间余量，使故障发生后虽仍有通信路径，却已不存在
可完成任务的合法协同延拓。

候选问题为：

> 能否在不预知具体故障实例的条件下，使多 UAV 策略在执行名义任务时主动保留可量化的
> 协同恢复余量，从而改善突发结构损失后的任务接续能力？

这里的研究对象不是“拓扑是否连通”，而是给定当前联合物理状态、合法局部信息和剩余资源后，
是否仍存在满足任务约束的去中心化接续策略。

### 暂定数学对象

定义故障族 `F` 和剩余时限 `H_r`。对联合历史 `h_t`，候选的协同恢复余量不是单个价值函数，
而是满足任务接续条件的故障—接续对集合：

`R(h_t) = {(f, omega): omega is legal after f and reaches the task terminal set within H_r}`。

需要进一步定义一个可计算、可学习并且不泄漏执行期全局真值的 margin `M(h_t)`。方法只有在
以下两点同时成立时才值得实现：

1. `M` 对未来故障后的任务接续成功具有预测效度；
2. 控制 `M` 能改变故障前行为，而不是退化为一般风险厌恶或奖励塑形。

### 必须产生的反事实预测

- 在名义回报近似相同的状态对中，恢复余量较大的状态在未见故障时间/类型下应有更高接续率；
- 只做故障后 reactive repair 的方法无法恢复已经在故障前耗尽的位置、能量或时限余量；
- 去掉 recoverability objective 后名义性能可以相当，但故障后的可行接续集合更快塌缩；
- 仅优化通信连通性不能替代任务层恢复余量，因为连通图仍可能没有可行任务延拓。

这些预测若无法在零训练小环境中构造反例与正例，则候选 A 立即停止。

### 最小受控消融

| 方法 | 名义任务策略 | 故障后 reactive repair | 故障前 recoverability shaping |
|---|---:|---:|---:|
| MAPPO | 是 | 否 | 否 |
| Reactive-Repair MAPPO | 是 | 是 | 否 |
| Connectivity-Regularized MAPPO | 是 | 是/否 | 仅图连通性 |
| 完整候选 | 是 | 是 | 任务层恢复余量 |

这组对照分别排除“只是更强基线”“只是故障后重规划”和“只是保持通信图连通”三种解释。

## 训练前硬门槛

候选 A 当前状态为 `FORMULATION_CANDIDATE`，不是训练方案。进入实现前必须全部通过：

1. **最近邻门**：完成 viability kernel、contingency planning、resilient task allocation、
   recovery RL 与 fault-tolerant MARL 的定向全文审计；
2. **定义门**：给出 `M(h_t)` 的唯一数学定义、执行期可观测输入和不可用真值；
3. **非退化门**：构造连通性相同但任务恢复余量不同的状态对；
4. **可识别门**：在无训练枚举环境中验证 `M` 能排序后续故障接续率；
5. **任务门**：基线可学习、名义不饱和、故障后不全失败；
6. **消融门**：四个对照只改变声明的机制，参数量与预算可匹配；
7. **预算门**：先用解析/枚举 Q0，再做短基线 Q1；禁止直接上百万步多方法训练。

任一门失败都停止或重构，不能用结果好看来替代。
