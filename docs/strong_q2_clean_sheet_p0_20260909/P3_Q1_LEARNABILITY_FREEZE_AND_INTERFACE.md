# P3-Q1 微型可学习性试验：冻结合同与训练接口

## 目的

Q1 只回答投稿级 P3 任务能否被标准循环 MAPPO 学习。它不比较新方法，不搜索参数，也不产生
论文主结果。这样可以在投入四方法因子实验之前，将“任务不可学习”与“候选方法无优势”分离。

## 冻结预算

- 方法：仅 `recurrent_mappo`；
- 新训练 seed：98311、98312、98313；
- 每个 seed：7,812 回合，每回合 64 个物理步；
- 每个 seed：499,968 个物理步，共 1,499,904 个物理步；
- 93 次更新，每次 84 回合，固定终点，不选择 checkpoint；
- 训练仅使用 P3A 冻结的 5 个训练 cell；两个组合留出 cell 只用于探索性评估；
- 每个 cell 固定评估 40 回合。

该预算是止损型筛选预算，不是由先前 DRTP 的 10M 惯例推导，也不预设最终正式预算。若 Q1
刚好通过，后续仍需用学习曲线和成熟度审计决定正式训练长度。

## 方法接口

共享循环 actor 读取各智能体 45 维合法本地观测，经 64 维编码和 GRU 后输出：

1. 领导机和跟随机的 `commit/defer/fallback` 分类分布；
2. 三个智能体的二维高斯制导分布。

中继机不参与高层模式损失，但其连续制导仍由策略学习。集中 critic 只读取三个合法本地观测
的并集（135 维），不读取交付、ACK 或版本匹配的 evaluator 真值。

## 技术 smoke 结果

`P3_Q1_INTERFACE_PASS_TO_RUNNER_IMPLEMENTATION`

- 混合动作张量形状正确；
- 一个 8-epoch 闭环回合可完成；
- PPO clipped surrogate、熵项和 critic 损失均为有限值；
- actor 与 critic 梯度非零且参数实际变化；
- Q0 通过记录、预算算术、seed 注册和 train/held-out 隔离均有效；
- 科学训练仍被锁定。

技术 smoke 使用 64 个环境步和一次临时 PPO 更新，仅验证训练管线连通性，不写入正式
checkpoint，也不构成可学习性证据。

## Q1 质量门

至少 2/3 seed 必须同时满足：相对最佳常量模式的平均任务值提高至少 0.5、联合成功率不低于
0.15、单边进入率不高于 0.35、碰撞与约束违规之和不高于 0.10，且任一高层模式占比不得超过
0.90。组合留出结果不作为继续条件，避免用探索性结果决定开发。

只有该门通过，才允许实现并评估 P3A 的四方法因子矩阵。未通过时按冻结合同停止，不自动延长
seed、不调整奖励、不修改任务，也不把 Q1 结果写成候选方法失败。
