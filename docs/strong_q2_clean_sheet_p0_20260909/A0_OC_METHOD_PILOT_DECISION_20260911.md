# A0 OC-MAPPO 开发门结论（2026-09-11）

## 证据层级

本文件仅解释 `results/development/a0_oc_method_pilot_20260911/` 的开发性 3 seed pilot；它不是确认性实验，不扩大为论文样本，也不与任何历史结果合并。

协议为冻结的 `A0-OC-MAPPO-METHOD-PILOT-V1`：Plain、OC 与 Shuffled-OC 各三个训练 seed、128 updates、12 并行环境、固定 64 episode 端点评估；Zero-OC 对 Plain 的端点参数严格一致。

## 完整性

- 九条主轨迹与九个固定端点评估均存在；
- OC 与 Shuffled-OC 的信用遥测非零且有方差；
- Plain 信用严格为零；
- `Zero-OC` 与同 seed Plain 的 checkpoint 参数逐项一致。

因此，此次结果可以用于判断干预方向，而非实现错误或 arm 不公平。

## 结果

OC 相对 Plain 的回报差在三个 seed 上为 `-4.372`、`+0.417`、`+0.550`；相对 Shuffled-OC 为 `-4.216`、`+0.889`、`+0.140`。两类比较均没有稳定正向方向。

更关键的是，OC 三个 seed 的平均估计误差均高于 Plain：`+0.064`、`+0.038`、`+0.035`。在 seed 99511，OC 的近碰撞步数从 `0` 上升至 `9.875`，同时回报显著降低。虽有两个 seed 的后验 log-det 下降，但这一代理端点没有与主要估计误差和可靠性端点形成一致改善。

## 决定

`A0_OC_DEVELOPMENT_STOP`。

不进入正式训练，不增加 seed，不延长训练预算，不扫描边际权重，也不通过修改奖励、网络、动作接口或安全规则挽救结果。

此次 pilot 支持的唯一事实是：公开 belief 的边际量可以以合同指定的方式注入优势且产生非退化训练信号。它**不支持**该归因提高动态主动感知的估计质量、任务回报或可靠性，也未显示其相对于同分布 shuffle 的可辨识优势。
