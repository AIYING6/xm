# P39 异步观测下的异构 UAV 持续协同跟踪：训练前合同

## 状态

`CONDITIONAL_ENVIRONMENT_BUILD_ONLY`：允许进行最小、非对抗环境设计与零训练审计；
不授权方法训练、云端实验或论文主张。

## 选题（务实二区定位）

**异步且不完美观测下的异构 UAV 持续协同跟踪与角色重构。**

研究对象是多个时变民用监测事件（例如移动污染源、灾害热点或失联目标）的持续覆盖；
不使用拦截、攻击、武器分配或对抗打击语义。团队成员具备不同传感范围、更新频率和
续航代价。角色重构的目标是维持事件覆盖，而不是静态任务分配。

## 已核验的资产边界

- `envs/uav_intercept_3d_env.py`：具有异构角色、局部缓存年龄、消息时效与 3DOF
  动力学，但只有单一对抗性目标和拦截式任务语义；不得直接作为 P39 的正式环境。
- `envs/uav_pursuit_env.py`：支持多个目标，但为 2D 追逃底座，缺少 P39 所需的异构
  传感、异步观测和持续覆盖端点。

因此，P39 不是“修改一个开关”的实验，而是新增一个保持标准 `reset/step` 接口的
非对抗环境适配器。既有 DRTP 与拦截证据链不得改写。

## 唯一拟研究方法差异（尚未冻结名称）

标准 role-aware recurrent MAPPO 与候选方法应保持：

- 相同策略/价值骨干、参数量级、奖励、训练预算、动作接口、环境转移；
- 相同局部观测、观测缓存和角色候选集合；
- 相同集中训练、去中心执行协议。

候选方法唯一允许差异为：**显式区分“保持当前跟踪责任”与“触发角色重构”的决策，
并把本地观测时效和预测覆盖缺口作为该决定的输入。**

若该差异可由固定阈值、贪心最近目标或普通 GRU-MAPPO 无损替代，P39 停止，不再
命名方法或扩展训练。

## 必须先通过的零训练门

| 门 | 必须证明的事实 | 停止条件 |
|---|---|---|
| E1 | 多事件覆盖确有非饱和区间，名义基线能完成部分而非全部事件 | 全失败或全饱和 |
| E2 | 至少两种角色重构动作在相同当前几何下因缓存时效/未来覆盖不同而有不同最优结果 | 固定最近规则可支配 |
| E3 | 角色切换既有收益也有可测代价（切换开销、短时失覆盖或能耗），不存在“每步重构”支配 | 始终切换或从不切换支配 |
| E4 | 缓存年龄改变的是合法预测质量或未来覆盖风险，而非隐藏标签或事后奖励 | 信息泄漏或人为标签 |
| E5 | 固定规则、GRU-MAPPO 和集中信息 oracle 可形成可区分的三档对照 | 三者无差异或规则贴近 oracle |

## 预设对照与消融

仅在 E1--E5 全过后，冻结如下对照：

1. 静态角色 MAPPO；
2. 每步贪心重分配；
3. GRU-MAPPO（同参数量级）；
4. 候选方法；
5. 集中信息 oracle（仅作上界）。

核心消融只有两项：去掉时效输入；将学习到的重构决策替换为匹配频率的随机切换。
不得追加模块堆叠。

## 正式端点（尚未计算）

- 持续覆盖率和未覆盖时长；
- 事件跟踪误差；
- 重构频率与无效切换比例；
- 最差训练 seed；
- 能耗/安全约束分别报告。

## 论文边界

P39 最多定位为一个严格受控的异构持续监测 MARL 方法研究。它不是新的“通用任务
分配框架”，不应声称解决无人机群协同或对异步信息普遍鲁棒。
