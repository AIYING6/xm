# P7 最终候选：拓扑条件化共形风险控制（TC-CRC）

日期：2026-09-10  
状态：`FINAL TOPIC SELECTED / ZERO-TRAINING FEASIBILITY`

## 研究问题

现有多无人机 MARL 工作通常以平均回报或成功率评价冻结策略，但部署者真正需要回答的是：在当前通信拓扑和任务上下文下，该策略的任务失败风险是否低于可接受阈值，以及证据不足时是否应拒绝自主执行。全局平均不提供这一判断；普通神经网络置信度也不具有可审计的风险覆盖含义。

TC-CRC 研究如何利用独立校准轨迹，为冻结 MARL 策略构造拓扑条件化的任务风险上界，并在风险超过阈值或校准支持不足时触发选择性拒绝/回退。核心目标不是再次提高 DRTP 的平均分，而是将“策略表现”转化为“带有限样本风险控制的部署决策”。

## 为什么该选题不再依赖脆弱的任务构造

- 不需要人为设计多个互补策略；单个冻结策略即可检验风险校准；
- 不要求重新训练 DRTP 或发明新采样器；主要方法差异发生在部署风险层；
- 成败由覆盖率、风险违反率和 coverage–utility 曲线直接判断，不依赖主方法必须赢过所有 seed；
- 可先用已归档的正式 A/B 原始 episode 做零训练可行性审计，再决定是否采集新的时序特征和正式独立测试集。

## 可检验贡献

1. 将通信拓扑退化下的多无人机策略部署表述为带风险容限的选择性决策，而非仅比较平均任务回报；
2. 设计拓扑分层、支持度感知的共形风险控制，使不同故障组拥有可审计的有限样本风险界限；
3. 在独立策略种子、独立校准/测试轨迹和结构变化条件下，评价风险违反率、覆盖—效用折中及相对全局校准的收益。

## 主要对照与消融

- 未校准神经风险分数；
- 全局 split conformal；
- 按拓扑组独立校准；
- 层级收缩的 TC-CRC（完整方法）；
- 去掉支持度回退；
- oracle 风险标签仅作为上界，不能作为可部署基线。

## 证据与统计

主要端点为任务失败或超时；碰撞、约束违规和回报低于阈值分别报告。核心指标为经验风险违反率、目标风险覆盖、选择覆盖率、选择后任务效用、区间宽度和最差拓扑组违反率。

策略层结论以训练 seed 为独立单位；在某个冻结策略内部，独立 episode 可作为校准样本，但不得把 episode 数冒充独立策略重复。A/B 队列不得池化成伪造的 n=10 确认性样本；一批用于开发/校准，另一批用于锁定测试，最终仍需新的独立部署评估确认。

## 最近工作边界

共形策略评价已经研究回报区间，CAMMARL 已研究其他智能体动作的共形集合，通用风险厌恶校准也提供了决策理论基础。因此本文不能把“把 conformal prediction 用到 MARL”作为创新。最低创新成立条件是：拓扑分层与支持度处理相对全局校准显著降低最差拓扑组风险违反，同时保持有用的选择覆盖率；否则该方向只是一项应用性后处理，应停止。

## Stage-0 停止条件

在任何新训练前必须确认：正式资产来源完整；失败端点不退化；每个拓扑层有足够事件；校准与测试能够独立；部署特征不使用未来结果；全局校准确实存在拓扑条件失配。任一项失败即停止 TC-CRC，不通过改风险阈值或合并不相容历史实验救题。
