# P3-Q0：投稿任务零训练实现审计

## 结论

P3 投稿任务的最小闭环实现通过全部 12 项冻结 Q0 检查，判定为
`P3_Q0_PASS_TO_TINY_LEARNABILITY_PILOT`。该结论只授权构建有明确止损条件的微型可学习性
pilot；不授权正式训练，也不构成任何方法性能证据。

## 实现对象

`EpistemicCommitmentP3Env` 将三架异构 UAV 的高层承诺决策连接到
`UAVIntercept3DEnv.step_guidance`。每回合包含 8 个决策 epoch，每个 epoch 执行 8 个物理步。
侦察领导机和攻击跟随机同时输出 `commit/defer/fallback` 与连续转向、爬升残差；中继机输出
连续制导。加速度边界保护仍由固定控制器承担。

通信调度器只决定计划和 ACK 在何时进入对应智能体的本地收件状态。actor 观测不包含全局
交付真值；集中 critic 的输入只是三个合法本地观测的并集。交付、ACK 和版本匹配真值仅写入
evaluator telemetry。

## 轨迹端点与防捷径设计

所有任务端点均由闭环位置轨迹、进入时序、末端队形和安全事件重建：

- 联合成功要求领导机与跟随机均进入任务区、进入时刻接近且末端队形误差不超过 2.5 km；
- 单边失败要求轨迹实际形成单边风险区进入；
- 恢复要求单边进入已经发生，随后轨迹显示跟随机撤离且领导机继续进入趋势被明显制止；
- 保守降级要求双方未进入风险区且末段持续撤离；
- 碰撞、约束违规和能耗来自 3DOF 后端遥测。

端点判定不读取 `plan_delivery`、`ack_delivery` 或 `plan_freshness` 真值，也不按
`commit/defer/fallback` 标签直接赋予成功或恢复。相同模式在不同私有消息状态下产生不同
制导和物理轨迹，从而使通信不一致通过合法信息路径影响任务结果。

## Q0 结果

| 冻结检查 | 结果 |
|---|---:|
| 全部 7 个训练/组合留出通信 cell 可达 | PASS |
| 私有观测关系精确 | PASS |
| 正常回合至少 4 个决策 epoch | PASS |
| 模式变化改变闭环制导与轨迹 | PASS |
| 单边进入由轨迹产生 | PASS |
| 存在脚本化安全成功 | PASS |
| 存在脚本化单边失败 | PASS |
| 存在脚本化失配恢复 | PASS |
| 常量模式不支配可行行为 | PASS |
| 正常通信条件不呈策略无关饱和 | PASS |
| 碰撞与约束遥测有效 | PASS |
| 运行状态恢复精确 | PASS |

脚本化联合承诺在“计划当前且正常送达”条件下得到联合成功；计划丢失时，单边承诺产生实际
单边进入；早期切换保守制导能够在终点前制止继续进入。三个常量模式跨冻结通信 cell 的平均
任务值分别为 4.286、0 和 2.000，而用于证明行为可分性的 evaluator-oracle 脚本为 5.429。
该 oracle 只证明任务不是常量策略即可支配的退化构造，不进入任何公平方法比较。

## 证据边界与下一门

Q0 证明任务事件可达、观测不泄漏、动作能改变物理轨迹、端点不是标签查表、安全遥测有效且
checkpoint 可精确续接。Q0 不证明神经策略能够学习，也不证明信息集承诺方法优于循环 MAPPO。

下一步仅允许 P3-Q1 微型可学习性 pilot。启动前必须冻结：训练 cell 分布、极小训练预算、
独立 seed、统一评估 tape，以及“基线不可学习、任务饱和、常量模式占优或隐私审计失败即停止”
的质量门。P3-Q1 通过后才可讨论小规模方法区分实验。
