# P39 Stage-0 V1 审计输出作废说明

`artifacts/diagnostics/p39_async_role_tracking_stage0_20260911/` 中的 V1 输出不应用于
候选裁决。

原因是审计器在 E4 的“新鲜缓存”分支中直接读取了 reset 后的过期缓存，而没有先将
对应缓存置为新鲜。因此其中 `fresh_coverage=0` 不是该反事实的实际测量值。

这是一处审计实现错误，不是环境、种子、奖励、速度、缓存时限、黑屏时长或通过门槛
的事后修改。V2 保留所有冻结任务参数和门槛，仅修复 E4 测量顺序，并写入新的输出
目录。V1 文件保留以保证审计可追溯性。
