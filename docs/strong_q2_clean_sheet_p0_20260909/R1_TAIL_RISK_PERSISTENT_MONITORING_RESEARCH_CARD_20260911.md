# R1：尾部服务失效约束的异构多 UAV 持续监测

## 状态与边界

`R1_CANDIDATE_Q0_AUTHORIZED`。本文件仅授权零训练任务审计；不授权提出算法、实施训练、生成论文主张或复用任何 DRTP/A0 结果。

## 研究问题

在持续监测中，平均信息新鲜度或平均覆盖率可以掩盖少数关键区域的长时间失服务。对异构 UAV 协同系统，真正需要检验的不是“能否降低平均 age”，而是：在能量、运动时间和同时发生的区域需求约束下，分散策略能否降低关键区域服务空窗的尾部风险，同时保留可接受的平均监测效益。

这里的服务失效是民用持续巡检/灾后态势感知中关键区域未被及时复核的事件，不涉及攻击、目标选择或伤害性自主决策。

## 与拥挤问题的区别

R1 不以一般动态任务分配、平均 AoI、平均路径长度或“加入 GNN/MAPPO”作为贡献。近期多 UAV 文献已经覆盖协同搜索与跟踪、动态调度和平均 AoI 优化。R1 的必要问题缺口是**平均任务效益与关键服务空窗尾部风险的不可约冲突**：一个平均意义上高效的策略仍可能反复牺牲低频但高后果的区域。

该差异尚未被证明新颖；后续文献核对必须排查多 UAV 持续监测、风险敏感 MARL、CVaR 目标和机会约束中的直接重合。

## 最小任务合同

1. 三架异构 UAV 在二维连续区域移动；每架具有不同巡航速度、探测半径与续航预算。
2. 四个固定监测区域的服务年龄随时间递增；进入可服务范围后，合法巡检将该区域年龄重置或显著降低。
3. 每个区域具有公开、随时间变化的关键性权重；至少一个关键区域的失服务阈值低于普通区域。
4. 运动、补给和区域服务互相排斥：一个 UAV 前往补给或远区巡检时，不能同时覆盖其它区域。
5. 环境回报只提供密集、可审计的服务改善与运动代价；尾部风险端点独立记录，不混入后验解释。
6. actor 只接收自身状态、局部区域服务状态及公共任务公告；不得接收未来需求真值、oracle 分配或全局 critic 输入。

## Q0 必须回答的问题

Q0 不训练。它必须证明以下四项同时成立：

| 判据 | 所需证据 |
| --- | --- |
| 非平凡风险 | 固定规则中存在非零但非全局的关键服务失效 |
| 决策叉 | 相同总体年龄或相同即时收益下，至少两类局面要求不同的服务/补给选择 |
| 常数规则不足 | 任一固定优先级规则均落后于可见状态 oracle，且 oracle 间隙非零 |
| 非饱和可行性 | oracle 也不能在所有情境同时达到零失效和最大平均服务收益 |

若任一失败，永久停止 R1 的当前任务定义；不通过改阈值、扫奖励或增加场景来挽回。

## 未来方法的可识别性要求

若 Q0 和后续 plain-MAPPO 学习门均通过，候选方法必须是**执行期优化目标或约束机制**，而非训练样本重加权。最小比较应为：

- Plain-MAPPO：仅优化团队平均服务回报；
- Mean-risk：显式惩罚平均服务年龄；
- Tail-risk：优化预先定义的关键服务空窗尾部端点；
- 完整方法：仅当其相对 Tail-risk 仍有独立、可消融的执行期机制时才允许提出。

训练种子是统计单位；每一策略必须同时报告平均服务效益、最大服务年龄、尾部 CVaR、关键区域失服务概率、碰撞、能耗和任务完成率。任何平均收益提升都不得自动解释为更安全或更可靠。
