# P9 强二区新课题收口：不完全信息对抗中的反事实响应包络

**阶段：** 零训练选题、新颖性与可识别性审查  
**决策：** 只保留一个首选题；不授权方法实现、性能训练或云端打包。  
**暂定名称：** Counterfactual Response Envelope for Team Adversarial Decision-making（CRE）  
**暂定中文题目：** 面向不可辨识对手策略的多无人机团队反事实响应包络决策

## 1. 为什么重新选这个问题

现有无人机对抗与多智能体学习已经广泛覆盖层次策略、目标分配、对手意图推断、循环记忆、策略种群和通用鲁棒优化。仅把 GRU、对手分类器、注意力或 PSRO 接入空战环境，不足以形成强二区的新机制。

本题研究一个更窄、可检验的决策缺口：在有限观测历史下，多个对手策略可能仍然不可区分，但己方候选团队机动会诱发不同的对手后续响应，因而具有不同且可能相反的最优选择。核心问题不是“对手属于哪一类”，而是：

> 当当前证据只能确定一个兼容对手策略集合时，如何利用动作条件的反事实响应包络，选择在所有仍然可信的对手延拓下后悔值受控的团队战术？

## 2. 候选机制及唯一干预

给定己方联合历史 \(h_t\)，定义与历史一致的对手策略版本空间

\[
\mathcal{B}(h_t)=\{\beta: d(\beta,h_t)\le \epsilon_t\}.
\]

对候选团队战术 \(a\) 和兼容策略 \(\beta\)，预测有限时域任务价值 \(Q(h_t,a;\beta)\)。动作 \(a\) 在策略 \(\beta\) 下的反事实后悔值为

\[
r(h_t,a;\beta)=\max_{a'\in\mathcal A_T}Q(h_t,a';\beta)-Q(h_t,a;\beta).
\]

CRE 的决策对象是最坏兼容响应下的后悔值：

\[
a_t^{\mathrm{CRE}}=\arg\min_{a\in\mathcal A_T}\max_{\beta\in\mathcal B(h_t)}r(h_t,a;\beta).
\]

主要受控对照使用相同历史编码器、响应预测器、候选动作集、参数预算和训练数据，仅把集合决策替换为后验均值下的期望价值最大化。由此隔离的唯一主要变量是：**点估计期望响应决策，还是兼容响应集合上的反事实遗憾决策**。

这不是 DRTP/PLR 的训练样本重加权，也不是对手标签分类；部署期决策会随兼容策略集合及候选动作的反事实响应而改变。

## 3. 三候选硬筛选结果

| 候选 | 严格决策对象 | 与拥挤近邻的差异 | 可做因果消融 | 工程代价 | 决策 |
|---|---|---|---|---|---|
| CRE：反事实响应包络 | 兼容对手延拓集合上的动作条件最小最大后悔 | 不输出单一类型或单一 posterior mean；直接优化响应集合上的团队决策遗憾 | 集合表示、反事实动作条件、regret selector 可分别匹配消融 | 中等，需要小型对抗环境和响应模型 | **保留** |
| 对手意图识别层次 MAPPO | 潜变量/类别条件策略 | 与既有 opponent modelling、Bayesian intention inference、hierarchical MARL 高度重合 | 可消融但难证明新机制 | 中等 | 淘汰 |
| 策略种群覆盖与鲁棒 best response | 对手种群上的响应多样性 | 与 PSRO、response diversity、population curriculum 高度重合 | 需要大规模种群训练，因果链长 | 高 | 淘汰 |

## 4. 必须先成立的严格反例

训练前必须构造一个有限、可枚举的两阶段团队对抗博弈：

1. 两种对手策略 \(\beta_1,\beta_2\) 在决策时刻之前生成完全相同的合法观测历史；
2. 对至少两个己方团队战术 \(a_1,a_2\)，最优排序在 \(\beta_1\) 与 \(\beta_2\) 下相反；
3. 后验均值最优动作存在严格正的最坏后悔，而 CRE 动作具有严格更小的最坏后悔；
4. 当后续证据使版本空间收缩为单一策略时，CRE 退化为对应策略的普通 best response；
5. 差异不能来自额外真值、更多历史、更多参数或不同候选动作集。

若上述反例不能同时成立，本题立即关闭。该门比“在若干 seed 上均值更高”更早、更严格地验证方法是否拥有独立决策价值。

## 5. 论文级可识别性设计

### 5.1 主要比较

- Posterior-mean response policy：相同模型与容量，按期望价值决策；
- Robust-value policy：相同版本空间，但优化最坏价值而非最坏后悔；
- CRE：完整反事实响应包络；
- Recurrent MAPPO：信息集和参数量匹配的模型自由基线。

### 5.2 受控消融

| 消融 | 删除内容 | 回答的问题 |
|---|---|---|
| Point-CRE | 将版本空间压成 posterior mean | 集合不确定性是否必要 |
| No-CF | 不枚举候选动作条件响应，只编码历史 | 反事实响应是否必要 |
| Maximin-value | 最小化最坏损失而非最坏后悔 | 增益是否只是通用保守优化 |
| Uncalibrated set | 去掉覆盖率校准但保持容量 | 可核验的不确定性覆盖是否必要 |

### 5.3 机制指标

- 版本空间覆盖率与宽度；
- 最坏后悔、平均后悔及 oracle gap；
- 对手策略仍不可辨识时的战术切换率；
- 证据累积后的集合收缩与策略专门化；
- 团队任务成功、任务回报、损失/碰撞/约束违规分别报告；
- seen opponents、unseen mixtures、adaptive opponents 分层，不能混为一个样本量。

训练 seed 是独立统计单位；对手实例、时间步和 episode 不能冒充独立重复。

## 6. 创新上限与最近邻风险

当前检索表明，部分可观测多智能体决策、对手潜变量建模、未知/非平稳对手适应、鲁棒 POSG 和 minimax-regret RL 均已有成熟工作。因此 CRE 的创新不能写成“首次处理未知对手”“首次使用 minimax regret”或“首次在 UAV 中使用对手模型”。

可争取的独立贡献必须同时包含：

1. **问题对象：** 观测等价但动作响应分叉的团队对抗决策；
2. **方法对象：** 动作条件的兼容响应包络，而非单一对手 embedding；
3. **决策准则：** 对每个候选团队战术计算相对其策略条件 best response 的最坏后悔；
4. **证据对象：** 严格反例、集合覆盖校准、与 maximin-value/point estimate 的匹配比较，以及未见对手组合验证。

只做到“GRU + opponent encoder + conservative head”时，本题最多是普通二区边缘工作，必须停止。

## 7. 成本与阶段门

### P9-A：零训练最近邻与解析门

- 系统检索 set-valued opponent modelling、policy ambiguity、minimax regret、robust best response 和 action-conditioned opponent response；
- 完成逐项差异矩阵；
- 构造并枚举严格反例；
- 预算：0 GPU，1–2 天。

### P9-B：环境可识别性门

- 新建最小两阶段对抗环境，不复用会掩盖决策缺口的旧任务；
- 冻结观测等价类、对手策略族、候选团队战术和 oracle；
- 要求至少 20% 的冻结测试状态存在响应排序分叉，且基线可学习但不饱和；
- 预算：0–小量 GPU，不训练候选方法。

### P9-C：短程学习资格门

- 3 seeds、小预算；
- 先验证 recurrent/point baseline 可学习；
- CRE 必须在至少 2/3 seed 降低 held-out worst regret，且任务表现不劣于 point baseline 的预设容差；
- 任一关键项失败即停止，不扫参补救。

只有 P9-A、P9-B、P9-C 全部通过，才设计正式多 seed 实验。正式实验前同时冻结统计计划、消融、外推带、运行成本和停止规则。

## 8. 当前结论

CRE 是当前唯一值得进入下一道零训练门的题目，原因不是它保证有效，而是它具备四个此前候选反复缺失的条件：独立的决策对象、可枚举的严格反例、容量匹配的主要对照和方法失败时可明确否证的机制指标。
