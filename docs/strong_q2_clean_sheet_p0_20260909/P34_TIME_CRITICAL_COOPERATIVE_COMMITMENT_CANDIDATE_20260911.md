# P34 候选：时敏协同截获中的可逆承诺决策

> **状态：停止（最近邻任务对象碰撞），未实现环境、未授权训练。**

## 1. 为什么不直接做“多目标分配”

多 UAV 动态任务分配、目标重分配、资源约束联盟形成、分层围捕与协同追逃均已有密集研究。仅用 MAPPO/注意力/分层网络去做“分配多个目标”并不足以构成强二区算法问题。

本项目若进入该任务族，唯一可审查的缺口不是静态或在线分配，而是：**团队已经为一个目标投入部分、不可立即转移的协同截获进展时，面对新出现且会消失的截获窗口，何时应维持承诺、何时应释放并由谁接力。**

候选对象的物理来源是持续接近、跟踪质量、协同夹角与有限交战窗口，而非人为设置的离散任务价值表。

## 2. 候选任务：多目标、时敏、部分承诺的协同截获

一个最小任务至少包含：

- 两个以上具有独立机动的目标；
- 每个目标有随几何和机动变化的有限截获窗口，而非固定 deadline；
- 一个目标的有效截获需要 tracker 与 interceptor 在时间上兼容的支持，或需要两架机形成可行夹角；
- UAV 对某目标的连续逼近、跟踪或支援形成可测的**部分承诺状态**；中途释放会损失真实的几何/信息优势，而非扣一项人为切换罚分；
- 新目标或原目标机动会改变窗口排序，使“继续当前目标”“全队转移”“一机维持、一机接力”都在不同状态有可能成为最优；
- 各 actor 仅可见本地相对状态、已分配支持和合法局部观测；集中式 critic 可见联合状态。

这是一类“承诺管理”问题，而不是将目标 ID 输入策略后重新分配。

## 3. 与已拥挤方向的边界

| 已有方向 | 典型问题 | P34 必须显示的额外结构 | 若缺失时的结论 |
|---|---|---|---|
| 多 UAV 在线任务重分配 | 新任务到达后按距离、能量、deadline、通信约束重新竞标或分配 | 已投入截获几何的损失与目标窗口的连续演化共同决定是否释放 | 退化为常规重分配，停止 |
| 多目标围捕 / 追逃 | 目标分配、编队或包围策略 | 必须存在“维持局部优势”与“响应新窗口”的非支配时序冲突 | 退化为围捕/目标分配，停止 |
| 协同制导 / 多弹拦截 | 以拦截时间、角度或碰撞为核心 | 团队层面的部分承诺、角色接力和窗口失效须是真实决策变量 | 退化为协同制导，停止 |
| 一般资源调度 | 任务收益、容量或服务时间 | 资源稀缺必须由可服务的跟踪/截获几何产生，不得用抽象 token 替代 | 退化为调度，停止 |

## 4. 文献初筛的负面结论

下列工作表明 P34 不能使用宽泛的“多 UAV 目标分配”“动态重分配”或“分层围捕”作为贡献：

1. [Multi-UAV cooperative task reallocation in dynamic environments](https://doi.org/10.1016/j.aei.2026.105107) 已讨论事件触发的重分配、能量、机动、deadline 和通信约束。
2. [Scalable Pursuit–Evasion Game for Multi-Fixed-Wing UAV Based on Dynamic Target Assignment and Hierarchical Reinforcement Learning](https://www.mdpi.com/2504-446X/10/1/5) 已组合动态目标分配、分层决策和追逃。
3. [Cooperative pursuit with multiple pursuers based on Deep Minimax Q-learning](https://doi.org/10.1016/j.ast.2024.108919) 已覆盖多追捕者的协同追逃。
4. [Dynamic Target Assignment and Cooperative Decision-Making for UAV Swarms Based on Multiagent Reinforcement Learning](https://doi.org/10.1109/JIOT.2026.3686066) 已将在线分配引入 MAPPO 决策回路。

因此 P34 只值得继续做零训练资格审计，不能现在就命名新算法或宣称创新。

## 5. 进入实现前的资格门

P34 必须先通过以下解析门：

| 门 | 所需证明 | 停止条件 |
|---|---|---|
| C1 部分承诺真实存在 | 随连续逼近/跟踪/协同角度提高，继续当前目标的物理截获可行性发生材料变化 | 进展可瞬时无损转移 |
| C2 新窗口真实改变排序 | 对相同当前分配，目标机动/窗口变化能使维持、释放、接力在不同状态分别成为唯一或近唯一优选 | 一个策略长期支配 |
| C3 非抽象资源冲突 | tracker、interceptor 或支援位置不能同时为两个目标提供充分服务 | 可无代价并行服务 |
| C4 信息不完全但合法 | actor 不知未来机动或全局窗口，只见局部可获得量 | 必须依赖特权预测才能决策 |
| C5 基线学习性 | 容量匹配 MAPPO 在小 pilot 中可学但不饱和 | 全失败或全饱和 |
| C6 方法可识别性 | 未来方法相对于动态分配/当前状态策略只改变一个可消融机制 | 只能靠堆叠模块取得差异 |

## 6. 最近邻复核与当前决定（2026-09-11）

**裁决：`P34_STOP_BEFORE_STAGE0`。**

本轮复核发现，P34 的核心对象并不能仅凭“已有几何进展形成部分承诺”与动态多机器人/多 UAV 任务重分配清晰分开：已有工作已明确处理时间窗、当前承诺、动态任务到达、能量/机动约束、通信约束以及在线重分配；有的还将分配结果嵌入 MARL 决策回路。把切换损失改为连续追踪/逼近进展，属于合理的任务建模，但不足以自动构成独立算法机制。

尤其是，若候选方法的输出仍是“继续当前目标、转移目标或由队友接力”，审稿人可将其视为动态任务分配、合同网重协商、时窗调度或目标分配与轨迹跟踪的一个具身实例。除非能给出一个不等价的新决策变量或可证明的性质，继续 Stage-0 只会把该新颖性风险延后到环境实现和长训练之后。

本候选因此停止：不建立 C1--C6 任务审计，不实现最小 3DOF 适配器，不启动 MAPPO pilot。P18 的物理底座仍保留，但不得用“部分承诺”“时敏重分配”或“协同接力”名称重新开启 P34。
