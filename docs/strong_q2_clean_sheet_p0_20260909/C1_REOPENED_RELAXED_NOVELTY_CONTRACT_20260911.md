## 放宽后的新颖性边界

允许的近邻是“已知/演化能力下的任务分配”与“在线能力估计”。例如，既有研究已讨论根据任务进度更新机器人专长或能力。因此本文不得宣称：首次处理未知能力、首次自适应任务分配，或首次把这一问题用于 UAV。

唯一可讨论的方法缺口是：在**去中心化执行、无队友能力真值、仅可使用合法局部历史**的条件下，如何把能力不确定性转化为对不可逆协作承诺的、可校验的后验条件决策。该差异必须由对照实验，而非命名，来支撑。

## 暂定方法：后验条件协作承诺 MAPPO

暂定描述名为 **Belief-Conditioned Cooperative Commitment MAPPO（BC3-MAPPO）**，不是最终论文名。它的最小组成只能有两项：

1. **执行期后验状态**：每个 actor 仅由自身合法历史、公共成功/失败反馈与可达消息生成队友有效能力的概率表示；不得输入队友真值、critic 状态或 oracle 标签。
2. **承诺条件优势**：训练期 critic 在同一联合轨迹上估计“继续协作承诺”相对于“转向可单独完成任务”的反事实优势；该项只服务于 actor 的合法后验条件策略学习，不得成为奖励塑形或特权执行通道。

DRTP 不属于该方法核心；至多在后续训练稳定性研究中作为独立、默认关闭的训练暴露组件。这样主因果比较不会把能力后验、动态图通信和采样重权重混为一项干预。

## 必须先完成的三项方法设计检查

不启动长训练，直到以下三项均通过：

1. **信息隔离测试**：自动断言 actor 输入不含队友真能力、中心 critic 状态、训练/评价 tape 或 oracle 动作；并验证后验只随合法历史变化。
2. **非等价对照设计**：冻结四个 arm：无记忆 MAPPO、记忆 MAPPO、BC3-MAPPO、后验置乱 BC3-MAPPO。若完整方法仅等同于记忆 MAPPO，停止；若置乱后验不改变行为或端点，停止。
3. **外部可比性审计**：将已有未知能力任务分配文献列为近邻，而非主基线；明确其信息边界、求解范式和本方法的差别。若无法给出可测试的差异，停止而不以“UAV 应用”补充创新。

## 正式实验的最低证据结构（通过前不得删减）

- 主证据：公开 LBF 的训练内分布、能力先验转移与未见能力/任务组合；
- 应用证据：独立 UAV 协同任务，使用同一后验—承诺机制，不能新增特权输入；
- 机制证据：后验校准、共同搬运失败后的动作切换、置乱后验消融；
- 比较：匹配 MAPPO、匹配 recurrent MAPPO、完整方法、置乱后验；
- 统计：训练 seed 为唯一独立单位，任务回报、完成数、延迟、失败/约束违规分别报告；
- 边界：不将公开基准的结果外推为真实飞行验证，也不将真值能力上界当作公平基线。

## 停止规则

出现以下任一情况即不进入正式 10M 训练：

1. 记忆 MAPPO 与完整方法在后验利用、动作切换及端点上不可区分；
2. 后验置乱不损害行为或任务端点；
3. 任何优势需要向 actor 泄露能力真值、全局状态或 oracle 信息；
4. UAV 应用无法复现相同的信息—承诺结构；
5. 公开基准被常规基线全面饱和或全面失败。
