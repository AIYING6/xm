# A0 OC-MAPPO 方法与消融合同

## 授权状态

`A0_METHOD_IMPLEMENTATION_AUTHORIZED`。授权依据为：Q0 几何冲突通过、四 seed 普通 MAPPO 短预算复现通过、固定基线轨迹上的边际可观测性遥测非退化。该授权不等于方法有效性结论。

## 方法问题

普通 MAPPO 将团队后验不确定性减少作为共享回报。它能优化团队目标，但单个 UAV 的策略梯度无法区分：某次量测是真正补足已有视角的边际信息，还是与其他 UAV 高度冗余的重复量测。

令公开 belief 为 \(b_t=(\mu_t,P_t)\)，动作后各 UAV 的合法量测信息项为 \(I_i\)。定义完整联合后验与移除第 \(i\) 架 UAV 后的后验：

\[
P^{+}_{t}=\left(P_t^{-1}+\sum_j I_j\right)^{-1},\qquad
P^{+}_{t,-i}=\left(P_t^{-1}+\sum_{j\ne i}I_j\right)^{-1}.
\]

训练期边际可观测性贡献为：

\[
m_{i,t}=\log\det(P^{+}_{t,-i})-\log\det(P^{+}_{t}).
\]

它由公开 belief、UAV 位置、传感器范围及噪声构成；不使用目标真值、事后真实轨迹或部署期集中信息。

## 唯一训练差异

OC-MAPPO 保留普通 MAPPO 的 actor、critic、PPO clip 目标、环境回报、观测、动作、网络大小、预算和执行接口。仅将 actor \(i\) 的训练优势改为：

\[
\widetilde{A}_{i,t}=A^{\mathrm{team}}_t+\lambda\left(m_{i,t}-\frac{1}{N}\sum_jm_{j,t}\right),
\]

其中 \(\lambda=0.25\) 在训练前冻结。中心化项确保只重分配同一时刻的协作学习信号，而不向所有 actor 同时增加同方向的额外团队奖励。

该式是待检验的算法干预，不应预先写成“正确机制”或“理论保证”。

## 受控 arm

| Arm | 边际量来源 | actor 优势差异 | 用途 |
|---|---|---|---|
| Plain-MAPPO | 无 | 原始团队优势 | 主受控基线 |
| OC-MAPPO | 真实公开 belief | 中心化边际贡献 | 检验完整机制 |
| Shuffled-OC | 同批次随机置换的边际量 | 相同数学形式 | 检验是否仅是任意额外扰动 |
| Zero-OC | 零贡献 | 与 Plain 相同 | 实现一致性检查，不作为独立性能主张 |

不加入图网络、循环记忆、额外预测器、真值 teacher、奖励重塑或动作屏蔽。

## 正式训练前门

1. 三个 arm 的参数数量、actor 输入、执行动作和环境交互必须哈希一致；唯一允许差异为训练优势中的 \(m_{i,t}\) 来源。
2. Shuffled-OC 必须只置换 agent 对应关系，不改变边际量的边际分布、环境采样或随机种子登记。
3. 每个 run 必须记录 `m_i` 的均值、方差、正贡献比例及其与 actor 优势的相关性；这些是机制遥测，不是独立统计样本。
4. 正式端点按训练 seed 汇总：回报、估计误差、final log-det、失跟时间、碰撞、距离与量测次数。
5. 只有 Plain-MAPPO 多 seed 正式复现保持非饱和，才启动 OC-MAPPO 与 Shuffled-OC。

## 结果解释上限

若 OC-MAPPO 超过 Plain 和 Shuffled-OC，可表述为：在本文 bearing-only 主动感知设定中，基于公开 belief 的边际可观测性归因与更好的团队估计端点一致。不得表述为所有主动感知任务、所有传感器或真实飞行系统都必然受益。
