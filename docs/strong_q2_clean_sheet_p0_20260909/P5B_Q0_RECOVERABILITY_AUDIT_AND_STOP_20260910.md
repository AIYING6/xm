# P5-B-Q0：任务级可恢复性审查与停止决定

## 结论

`P5B_STOP_REDUCIBLE_TO_ROBUST_REACHABILITY_AND_CONTINGENCY_PLANNING`

P5-B 不进入学习器实现或训练。任务级可恢复性能够区别于即时安全、通信连通和故障后被动修复，
但没有通过更强的新颖性门：在目标和扰动族被明确后，它可写成目标条件化的鲁棒可达性/可行性；
多机器人规划又已直接研究沿名义计划保留应急可行性和主动安排 contingency tasks。

## 最近邻差异矩阵

| 最近邻 | 已解决的问题 | P5-B 的表面差异 | 审查结论 |
|---|---|---|---|
| Viability kernel / Reachability-constrained RL | 从哪些状态存在持续满足约束或到达目标的策略 | P5-B 强调团队任务完成而非单一安全集合 | 将终端集合换为任务完成集合、将扰动加入状态后，核心对象可被鲁棒可达性表达 |
| SCRAMPPI（2026） | 沿名义轨迹始终保持一条到安全集合的 contingency trajectory | P5-B 希望保留多个任务接续而非单个安全退路 | “沿途保留备用可达路径”的机制高度相邻，目标集合变化不足以单独支撑创新 |
| 主动 contingency-aware 多机器人分配（TASE 2025） | 在潜在失败发生前优化任务分配与调度，减少失败和瓶颈影响 | P5-B 拟由学习策略隐式保留延拓 | 科学问题已经存在；仅把优化器换成 MARL 不构成强创新 |
| 韧性与能量感知 MRTA（T-RO 2022） | 在能力/组件失效和能量约束下保持任务分配韧性 | P5-B 衡量当前状态的延拓集合 | 资源冗余、能力替补和失效适应已有直接覆盖 |
| Empowerment / option preservation | 用未来可达结果或控制能力衡量“保留选择” | P5-B 只计算与冻结任务相关的选择 | 任务条件化更具体，但“保留未来选择”并非新机制 |
| 故障后 plan repair | 事件发生后修复或重算计划 | P5-B 在故障前塑造状态 | 与 P5-B 可区分，但这不是最强最近邻 |

## 非通信解析例子

构造两个智能体、完全通信、同一待完成任务。任务需要任一存活成员拥有至少 2 单位能量：

| 状态 | 成员能量 | 即时安全 | 名义可完成 | 成员 0 失效后 | 成员 1 失效后 | 恢复比例 |
|---|---|---:|---:|---:|---:|---:|
| 保留储备 | `(2,2)` | 是 | 是 | 是 | 是 | 1.0 |
| 储备耗尽 | `(2,1)` | 是 | 是 | 否 | 是 | 0.5 |

这证明恢复比例不是即时安全、名义任务可行性或通信连通性的同义词。但若定义扰动族为“任一单
成员失效”、终端集合为“任务完成”，则“所有失效下都能完成”正是鲁棒目标可达性。因此解析
例子通过了非退化门，却没有通过与最强形式化邻居的差异门。

## 为什么不继续包装

可以把恢复比例改名为 margin、用神经网络估计、加入 MAPPO 辅助损失，并在 UAV 上得到曲线；
这些工作仍只会形成“学习近似鲁棒可达性并应用到多 UAV”的工程组合。若没有新的信息结构、
新的可识别对象或新的理论性质，实验成功也无法解决核心创新不足。

## 门控结果

| 门 | 结果 |
|---|---|
| 不依赖通信 | 通过 |
| 区别于即时安全/连通性 | 通过 |
| 区别于故障后被动修复 | 通过 |
| 区别于目标条件化鲁棒可达性 | **失败** |
| 区别于主动 contingency planning | **失败** |
| 最小可识别消融 | 不充分：大概率只比较估计器/正则项 |
| 强二区创新资格 | **不通过** |
| 训练资格 | **不通过** |

## P5 总结与下一步

P5-A 和 P5-B 均在零训练阶段停止。这个结果不是“没找到就降低标准”，而是表明两个初选方向都
无法同时满足独立科学对象、强最近邻差异和干净消融。

下一步不回到通信，也不重启 DRTP。进入 `P6_PROBLEM_DISCOVERY`：从**环境中尚未被决策变量
表示的现实不确定性**出发，而不是从算法名出发。优先审查三类问题：

1. 多智能体策略在任务规格在线变化时的约束组合与零样本执行；
2. 动力学/能力持续退化下的团队在线系统辨识与协同控制耦合；
3. 感知、控制与任务层不确定性跨时间尺度耦合时的联合适应。

每类先做最近邻和可识别性审查，不产生方法名称，不写训练代码。
