# M1 基础策略短试：奖励目标校正

## 观察

三条 32-update 的工程短试均收敛到近似固定的原地感知行为：

- 最大信息年龄均为 24（整个 horizon）；
- 累积重复感知约为 44–45；
- 轨迹距离约为 4；
- 随机合法策略的平均回报反而更高。

这批数据是环境工程诊断，不进入论文、不与后续训练合并。

## 原因与修正

初版奖励包含个体感知带来的局部不确定性降低与时效收益，但没有直接扣除：

1. 团队范围内未更新区域累积的公开信息陈旧风险；
2. 同一时刻多 UAV 对同一区域的重复感知。

这使“守住初始位置并反复感知”成为局部可得的回报路径，与任务定义的团队持续监测目标不一致。

修正后的统一奖励为：

\[
r_t=\Delta U_t+\Delta F_t-0.02C_t-0.10\sum_r a_r(t)\,u_r-0.15D_t,
\]

其中最后两项分别是公共信息年龄风险和本步重复感知数。它们由所有方法可见的后验年龄与 urgency 计算，不使用隐藏场真值，也不向 FUM-MAPPO 提供任何额外信息。

## 下一步

用相同三 seed、相同 32-update、相同并行数重新跑一次基础策略短试。只有仍出现固定行为塌缩时才停止 M1；若基线可学习且不饱和，再冻结更长的基础预算。
