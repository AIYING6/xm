# A0：可信 Q2 主线冻结（2026-09-11）

## 决定

在“必须是强二区候选”的额外约束下，当前候选池不应继续启动训练；但在用户已明确放宽为“能够形成可信二区论文”的条件下，A0 是唯一同时具备非退化任务、可学习基线、执行期信息公平、以及真实机制消融的可用主线。

因此冻结 A0 为 **Q2 开发主线**，工作对象是：三架异构 UAV 在 bearing-only 动态事件跟踪中，如何在不改变执行 actor 信息、网络容量、PPO 目标或环境回报的前提下，使用公开 belief 的边际可观测性量，改善训练期间对冗余与互补量测的协作归因。

## 主张上限

允许的论文主张是：在本文冻结的异构主动感知任务中，公开 belief 驱动的边际可观测性归因可作为团队回报 MAPPO 的可检验训练期补充，并在真实量、shuffle 与零量对照下评估其影响。

不允许主张：提出一般性信用分配理论、普遍优于 COMA/difference rewards、解决全部多 UAV 主动感知问题，或在没有实测外部比较前声称强二区算法创新。

## 已冻结的开发门

执行 `configs/a0_oc_method_pilot_v1.json`：

- `Plain / OC / Shuffled-OC` × 三个新训练 seed；
- 每条轨迹 128 updates、12 并行环境；
- 每个固定端点 64 episode；
- `Zero-OC` 仅作与 Plain 的参数等价性检查；
- 汇总训练 seed 级端点与信用遥测，不将 episode 作为独立训练样本。

开发门只决定是否值得做正式实验；不把三 seed 结果用于确认性论文结论。若 OC 不优于 Plain 与 Shuffled-OC，或存在安全/运动代价恶化，则停止 A0，不通过延长预算或修改权重补救。
