# M3 collapse/recovery temporal-analysis contract

**Protocol:** `M3-COLLAPSE-RECOVERY-TEMPORAL-ANALYSIS-V1`.

This is an archive-only, zero-training analysis of the six pre-specified M3
transition windows. Its precursor is the first half of each fixed interval and
therefore ends before the ending-milestone evaluation. It cannot select a
checkpoint, change a trajectory, tune a parameter, create an algorithm, or
alter Mainline A.

An actionable candidate would require a repeated precursor in both cohorts,
opposite or attenuated behavior before recovery, and a direct minimal
intervention mapping. Horizon sufficiency is judged independently.
