## Screen result

Candidate A has direct UAV-relay reconfiguration coverage (A1/A2). Candidate B has direct inconsistent-information decentralized allocation coverage (B1/B2) plus version-state scheduling (B5/B6). Candidate C has established stateful migration/failback/reconfiguration coverage (C1–C6) plus UAV failure recovery (A2). The literature record does not prove impossibility of a future special case, but it defeats any claim based only on recombining these axes.
