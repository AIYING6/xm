# DRTP 双轨项目治理冻结（2026-08-28）

## A 轨：应用型投稿收敛

目标是在当前证据边界内完成应用型 UAV/MARL Q2 投稿稿件。

- 主方法、UTR 主消融、MAPPO-NoGraph 外部参考、正式 2301--2305
  cohort、独立 2401--2405 cohort、cross-tape 诊断和附加未见条件评价均视为
  已完成证据。
- DRTP 不再修改；不启动 DRTP、R-DRTP、EGTR、SNR 或任何替代版本训练。
- 论文必须保留：正式 cohort 正向、独立 cohort 反向、训练 cohort/seed
  敏感性、后验附加未见条件评价的非确认性地位，以及不将各 cohort 合并的统计边界。
- 后续仅允许：稿件终审、参考文献核验、图表/统计表达、代码和数据可用性、目标
  期刊格式与投稿材料。附加未见条件评价结束后，不再为本稿增加训练实验。

## B 轨：独立机制探索

目标是把训练 cohort/seed 敏感性作为下一阶段研究问题，而不是为 A 轨补救结果。

- 必须在独立分支、独立实验合同、独立结果目录和独立论文叙事中开展。
- 起点只能是 failure-aware 行为 telemetry 与小预算机制筛查；不得凭既有相关性
  直接设计 Stable-DRTP。
- 机制 GO 的最低要求是跨坏 seed 重复、时间领先、UTR 同 seed 不具有同等强度，且
  至少形成 `sampler/q → 行为/协同 → 任务结果` 三层连续证据。
- 若筛查不能满足该门槛，则 B 轨 `NO-GO`；不得以更换阈值、增加模块或反复换 seed
  延长探索。
- 仅在机制 GO 后，才允许一个机制对应一个最小修改，并重新经过 development 和独立
  confirmation；该证据不回填或替代 A 轨已冻结结论。

## 隔离与停止规则

1. B 轨的失败、延迟或新负结果不得阻塞 A 轨投稿。
2. A 轨审稿期间的 B 轨结果仅可作为潜在修回储备；不得无理由改写已提交主稿。
3. 若 A 轨已接受，B 轨成果作为后续方法论文单独组织。
4. 两轨均禁止删除不利 seed、依据结果提升 checkpoint 或事后改变评价阈值。
