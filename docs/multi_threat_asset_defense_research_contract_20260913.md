# 多威胁双资产 UAV 防御对抗：G0 合同

本任务替代单红方双资产版本。后者的 G1 已证实：三架蓝方可始终集中处理唯一红方威胁，因而没有资源争用。本任务引入两架攻击者、两个空间分离资产，并要求蓝方在任何一项资产被打击前中和两项威胁。

它保留现有异构 3DOF 飞行动力学、27 原始动作、飞行约束与蓝方通信范围；不复用 DRTP、PSCR 或单威胁版本的结果。

红方在公开接近阶段后才分配至不同资产；分配由现实蓝方资产覆盖确定。分支前 actor 与 critic 均不接收未来分配标签。G0 仅验证动力学、时间顺序与信息边界。G1 必须证明集中拦截、分置防御和延迟响应各有终点层面的适用区域；失败则不训练、不提方法。
