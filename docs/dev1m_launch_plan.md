## Escalation Rule

Only move from 1M to 2M/5M/10M if at least one of these is true:

- EA-RG-MAPPO is still improving near 1M;
- baselines are unstable and need longer fair training;
- validation curves show the best checkpoint is near the end of 1M;
- the reviewer-facing main conclusion is not yet statistically separated.

If all methods saturate early or fail similarly, modify scenario difficulty or training protocol before spending 5M/10M steps.
