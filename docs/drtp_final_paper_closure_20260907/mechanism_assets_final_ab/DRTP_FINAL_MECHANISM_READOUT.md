# DRTP 最终 A/B 机制读数：训练暴露确实改变，但不作单一根因解释\n\n**数据状态：** A/B 完整归档均已 SHA256 验证；每批包括 5 个 DRTP 训练 seed、固定 10M endpoint condition summary 与完整 sampler telemetry。分析为只读：未解压或修改 checkpoint，未运行评估、训练或 checkpoint 选择。\n\n## 可支持的过程结论\n\n1. **DRTP 在全部十个最终训练 seed 中实质性地偏离了均匀故障组分配。** 以最终六组条件概率相对均匀分配的 L1 距离计，cohort A 为 0.512–0.646，cohort B 为 0.621–0.716。因此，Fig. 3 可作为“DRTP 实际执行了动态训练暴露重分配”的过程证据，而非仅仅展示算法定义。\n2. **终点困难度分布具有 cohort 依赖性。** A 中 CP 与 TE 的平均名义相对回报缺口较大（分别为 22.86、18.37）；B 中最大的组级缺口为 TE（7.89），其次为 CP（6.70）。这说明组级学习困难不是一个在两批中完全固定的排序。\n3. **记录难度与实际非名义组暴露的关联总体为正、但 seed 依赖。** 六个故障组内的 Spearman 描述性关联在 A 五个 seed 中为 −0.143 至 0.986（均值 0.414），在 B 中为 0.030 至 0.829（均值 0.486）。这与“困难组通常获得更多暴露”相符，但存在反向或很弱的个体 seed，因此不支持“每一个 seed 中同一难度链都严格成立”的表述。\n\n## 论文写法\n\n建议写为：\n\n> 最终训练 telemetry 显示，DRTP 在两个独立 cohort 的全部训练 seed 中均从均匀故障组分配发生了受约束的概率重分配；组级记录难度与实际暴露的关系在 cohort 汇总层面呈正向趋势，但存在 seed-dependent variation。该过程证据与 topology-aware robustness shaping 一致，不构成策略内部唯一因果机制的证明。\n\n禁止写为：\n\n- “DRTP 在每个 seed 中总是向最难拓扑分配最多样本”；\n- “该分析证明了 DRTP 的唯一根因”；\n- “图拓扑退化度与性能严格线性相关”。\n\n## 仍不能完成的部分\n\n当前 sampler manifest 给出了 F0/TE/TL/DS/DL/CP 的冻结组成员及故障时序，但未给出可计算的显式邻接矩阵或边集合。因此不能据此生成 broken-edge count、connectivity、reachable-pair fraction 或 shortest-path 的数值表。若后续找到对应的冻结图定义，可补充 Supplementary Table S1；如果找不到，主文只保留已可审计的条件组/时序语义与 exposure 过程，不伪造 graph-statistics 表。\n
