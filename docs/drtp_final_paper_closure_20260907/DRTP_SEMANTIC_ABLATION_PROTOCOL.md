# DRTP 拓扑语义消融：冻结执行协议

## 目的与边界

本消融仅用于区分“拓扑语义驱动的难度信号”与“任意动态调节概率”两种解释。比较对象为冻结的完整 DRTP、Random-DRTP 与 Fixed-DRTP；它不是新算法、不是参数搜索，也不用于修改 DRTP。

Random-DRTP 保留与完整 DRTP 完全一致的环境、PPO、网络、奖励、观测、动作、训练步数、故障条件库、概率约束、名义条件锚定、`q` 更新频率和更新幅度。唯一改变是：在训练开始前，以训练 seed 派生的确定性置换打乱“拓扑条件组身份—难度统计量”的对应关系。训练期间该置换固定，且不得读取最终评估带、不得按回报重排、不得人工挑选置换。

Fixed-DRTP 不使用开发集或终点评估来预先设定权重。它在冻结 warm-up 后的第一次合格难度估计处生成一次可行的 `q`，随后在整个剩余预算内保持该 `q` 不变。这是“静态困难加权”与连续反馈调整之间的可审计比较。

## 最小设计（若后续实施）

| 项目 | UTR | Fixed-DRTP | Random-DRTP | 完整 DRTP |
|---|---|---|---|---|
| 拓扑语义难度 | 否 | 是 | 否 | 是 |
| `q` 连续反馈更新 | 否 | 否（首个合格更新后固定） | 是 | 是 |
| 难度到条件组映射 | 均匀 | 原始语义映射 | 每个 seed 的冻结确定性置换 | 原始语义映射 |
| PPO/网络/奖励/接口 | 相同 | 相同 | 相同 | 相同 |
| 总步数与终点评估 | 相同、预注册 | 相同、预注册 | 相同、预注册 | 相同、预注册 |

主要分析单位是 training seed；报告均值、中位数、lower tail、配对方向、success、timeout 与 collision。不得以 pooled seed 替代独立 cohort 报告。
