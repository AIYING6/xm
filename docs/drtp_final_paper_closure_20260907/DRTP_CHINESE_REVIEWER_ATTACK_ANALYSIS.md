# DRTP 中文投稿稿审稿风险分析

## 核心论证

**主张：** 在所评估的冻结拓扑故障接口内，DRTP 通过拓扑语义化、名义参考且有界的 reset 侧训练暴露分配，显示出相对匹配 UTR 的重复 cohort-level 鲁棒性收益。

**最强证据：** 两批独立 five-seed cohort 的固定 10M endpoint、冻结 OOD、匹配 PLR-style 外部比较。

## 高概率审稿问题与论文内回答

| 审稿攻击点 | 论文内回应 | 不能越过的边界 |
|---|---|---|
| DRTP 是否只是 PLR 改名？ | 补充表 S1 明确采样对象、信号、故障语义、名义锚点与概率约束；表 3 采用匹配 PLR-style 比较 | 不声称 DRTP 在两批 cohort 中全面优于 PLR-style |
| 为什么只改 reset 分配？ | 表 1 明确 actor、critic、PPO、奖励、观测和动作接口不变，形成窄而公平的 UTR–DRTP 对照 | 不推断方法已学会新的通信协议 |
| 平均收益是否由偶然 seed 驱动？ | A/B 独立报告、固定 endpoint、最差 seed 与SD并列；不以 pooled n=10 作为主要结论 | 不声称逐 seed 一致提升 |
| OOD 是否等同真实鲁棒？ | 图 5、补充表 S2 只报告冻结 structural/parameter shift | 不外推至任意未知故障或实飞 |
| safety 是否全面改善？ | 表 2/3分开报告 timeout 与 collision，讨论中解释权衡 | 不合成安全分数、不保证安全 |
| 为什么缺少真实飞行？ | 在局限性中明确 simulation-only；结论保持训练协议层面的表述 | 不写“部署就绪” |
| 为什么只有三无人机？ | 6-UAV按冻结正式协议独立验证 | 结果未完成前不写跨尺度优势 |
| 是否缺少消融？ | 表 5保持诚实待填；PLR比较用于外部机制边界而非替代消融 | 不将 sampler 日志当作消融证据 |
