# PSCR P4：可靠度条件化承诺—重构 MAPPO 方法合同

**状态：** `METHOD_DESIGN_FROZEN_PENDING_G1_BASELINE`  
**目的：** 在昂贵训练前锁定唯一主机制、匹配对照、可识别消融与结论边界。  
**不使用：** 任何 DRTP 历史结果或既有 PSCR P1--P3 的开发性结果作为本合同的性能证据。

## 1. 任务缺口与可检验假设

P4 中，未来服务请求的空间扇区在到达前不可见；策略只能看到公开的预测扇区和其可靠度 `r`。在同一冻结几何下，透明 Q0 校准显示：

- 当 `r=0.90` 时，预测方向的前置承诺具有更高的期望服务价值；
- 当 `r=0.25` 时，公共中继枢纽的保守重构具有更高的期望服务价值；
- 两种选择都不以降低主服务成功为前提。

因此，待检验的不是“是否增加一个动作”，而是：**策略能否将公开可靠度转化为可恢复的、时序正确的预到达承诺，并在请求到达后释放到真实服务链。**

G0 的三条 Plain-MAPPO 轨迹均出现非零终点服务，满足最低可学习性门槛；其终点行为尚未稳定地形成上述条件化重构，因而不支持把普通 MAPPO 当作已经解决该缺口的基线。

## 2. 唯一主方法：RC-PSCR-MAPPO

**名称：** Reliability-Conditioned Predictive Service-Chain Reconfiguration MAPPO（RC-PSCR-MAPPO）。

### 2.1 保持固定的部分

环境动力学、3DOF 原语、五意图控制接口、PPO 目标、actor 参数量、执行时观察、奖励、训练预算、训练/测试可靠度带、随机种子登记与固定终点评估全部固定。执行 actor 仍只使用合法局部观测和公共预测可靠度；它不接收真实未来扇区、未来紧急度或任何未来 oracle。

### 2.2 唯一机制变化

RC-PSCR 在**训练期集中 critic**中加入一个行动条件化的公共机会价值头：对当前公开历史 `h_t` 和可行动作意图 `a`，估计“在未来请求到达前执行该承诺，随后在到达后释放至真实服务”的折扣服务机会值 `Q^c(h_t,a)`。

对可用的预到达意图集合 `A_pre={primary, forecast, contingency, hold}`，定义训练期承诺优势：

`A_commit(h_t,a)=Q^c(h_t,a)-mean_{b in A_pre} Q^c(h_t,b)`。

该优势只作为 actor 的辅助训练信号；PPO 回报目标不变。其作用是区分“现在向预测扇区承诺”“现在向公共枢纽重构”和“继续当前服务”在**公开可靠度与剩余时间**条件下的长期机会代价。到达后，future-service 意图解锁，原 PPO 轨迹回报和机会价值共同促使释放行为，而非将预置动作误当作最终目标。

### 2.3 方法不能主张什么

该方法不恢复隐藏位置、不预测真实紧急度、不改变执行信息集，也不保证每个 seed 都选择理论最优意图。其可检验贡献仅是：在匹配受控条件下，是否提升可靠度条件化承诺—释放行为及服务结果。

## 3. 预先冻结的比较臂

| 臂 | 可靠度语义输入 | 行动条件化机会价值 | 适用问题 |
|---|---|---|---|
| Plain-MAPPO | actor/critic 均见合法 `r` | 无 | 普通端到端 MAPPO 是否已可完成任务 |
| Phase-aware control | 合法 `r` | 无 | 仅增加到达前/后阶段表征是否足够 |
| Reliability-permuted RC | `r` 的边际分布相同，但在训练样本内置换 | 有 | 收益是否依赖可靠度—机会关系，而非额外价值头 |
| RC-PSCR-MAPPO | 正确合法 `r` | 有 | 主方法 |

所有臂使用相同 actor、critic 主干宽度、优化器、并行环境数、更新数和固定端点评估带。外部方法若加入，仅作为定位参考，不替代上述因果对照。

## 4. 主要端点和机制端点

### 4.1 主端点

训练 seed 为独立单位。每个 seed 在 `r=0.90`、`r=0.25` 两个冻结带分别进行等量终点评估，报告：加权服务值、主服务完成、未来服务完成、超时/过期、碰撞/约束违规（若出现）、能耗和最差 seed。

### 4.2 机制端点

在预到达阶段，报告 forecast-stage 与 contingency-stage 的意图比例；在到达后，报告 future-service 的释放比例。可识别的方向性预期为：

- 高可靠度带：RC 相对置换控制更频繁地使用 forecast-stage，且不牺牲主服务；
- 低可靠度带：RC 相对置换控制更频繁地使用 contingency-stage，且不牺牲主服务；
- 到达后：RC 不应长期停留在 forecast/contingency，而应增加合法 future-service 释放。

这些指标说明策略行为是否与方法假设一致；它们不单独证明内部价值估计的因果正确性。

## 5. 推进门槛

1. **G0 已通过：** 三个 Plain-MAPPO seed 均有非零终点服务，允许方法实现。
2. **G1：** 用固定完整预算建立 Plain-MAPPO 的稳定基线；要求多数 seed 保持非零主服务和非饱和未来服务。G1 失败则先修复任务学习地基，不解释主方法结果。
3. **M1：** 以小规模、全部四臂的匹配先导检验主端点、行动方向与安全代价；只有 RC 同时优于至少一个结构控制且无明显代价塌陷，才启动双队列正式实验。
4. **正式实验：** 固定方法代码、种子和端点后运行两个独立 cohort；不得用开发队列选择结论。

## 6. 结论边界

若后续结果仅显示总回报变化而无可靠度条件化行为或控制比较优势，本文只能报告一个复杂任务上的经验差异，不能写成“可靠度条件化承诺机制有效”。相反，即使机制行为成立，也必须将任务完成与安全/能耗代价分开报告。
