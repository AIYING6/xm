## 被禁止的文学主张

- “本文首次/首个/唯一提出图 MARL 用于多 UAV/空战/受限通信。”
- “现有研究均只报告终端成功率，未研究恢复速度。”
- “通信韧性或节点失效 UAV 决策此前没有研究。”
- “图关系编码天然带来 OOD 泛化或通信鲁棒性。”

如需写文学缺口，使用下列可核验的弱表述：

> 已有工作分别讨论图式空战决策、学习通信和受限通信 UAV 协作；本文将关注点限定为严格感知与中继失效条件下的任务级恢复时间，并以匹配失效暴露的事件时间分析报告该终点。
