# Phase S2 Claim–Evidence Boundary

## Allowed core claim

Relay-node failures induce reproducible relation-specific
communication-topology and path-composition changes associated with
mission-performance degradation. The proposed multi-relation graph
representation is evaluated for whether it reduces this degradation relative
to non-graph and capacity-matched merged-graph baselines.

## Allowed only after S3/S4 evidence

Multi-relation modeling improves robustness to Relay-node-induced topology
reconfiguration, if paired method comparisons and uncertainty support it.

## Prohibited

- Relay failure causes information loss;
- Relay is always the necessary information intermediary;
- the method restores lost information;
- strict recovery is a headline contribution;
- Role-Gate is a core contribution without separate evidence;
- information-loss causal mediation.
