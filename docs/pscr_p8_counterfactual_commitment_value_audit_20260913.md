# P8 反事实承诺价值审计

本审计先于任何新方法训练执行。它在标准 `PSCRSearchPrefixEnv` 接口中，将同一个 episode seed 与同一个公开可靠度下的两个合法承诺计划配对：维持主服务，或由 Scout/Relay 在公开预测扇区执行阶段布设、Executor 保持主服务。

每个配对分支只改变承诺窗口中的团队计划；未来请求激活后，两者使用相同的公开响应模板。未来扇区、紧急性与横向位置只在 episode 结束后作为审计记录比较，以证明分支共享同一外生实现，绝不作为前置计划输入。

该审计回答的是：标准 P8 任务中是否存在可靠度相关、方差可报告的计划价值差。它不训练策略，不能证明 PPO 可学习此信号，也不能作为论文中的方法效果证据。
