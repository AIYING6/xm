# P1 最终决策：问题真实性与 3DOF 可实现性

**裁决：** `P1_PASS_TO_ALGORITHM_DESIGN_NO_TRAINING`

## 已完成证据

| 门 | 结果 | 证据上限 |
|---|---|---|
| P1A 解析可辨识性 | PASS | 证明存在观测等价、动作冲突且主动探测有条件价值的最小问题 |
| P1B 最小语义状态机 | PASS | 证明接口可隐藏故障真值、探测有成本且运行态可复现 |
| P1C 3DOF shadow adapter | PASS | 证明相同 3DOF actor/share/graph observation 下，合法物理机动可区分超距与硬失效 |

P1B 在 2,000 个 seed/假设的零训练采样中得到：

- 可恢复超距回执率：0.8925；
- 硬失效回执率：0.1100；
- 经验回执差：0.7825；
- 七项语义检查全部通过。

P1C 使用现有 `UAVIntercept3DEnv`：

- 探测前 actor、centralized share observation 和全部 graph tensor 完全一致；
- 12 步中继接近机动后，可恢复超距链路回执为真，硬失效为假；
- 中继能量成本为 0.0044997；
- 两种原因均无碰撞、无约束违规；
- runtime save/restore 后结果完全一致。

允许进入 P2 算法设计与纯单元测试；不授权 PPO 训练。新算法不得以故障分类准确率或 belief entropy 为最终优化对象，而必须直接度量信息对团队恢复决策的价值。
