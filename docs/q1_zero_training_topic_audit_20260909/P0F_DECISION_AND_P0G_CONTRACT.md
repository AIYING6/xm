# P0F 决策与 P0G 合同

## 直接决策

现有 DRTP 稿件与新算法项目应正式分离：

1. **DRTP 论文线**：按现有正式 A/B、OOD、PLR、机制遥测和有效实验收口；不再承担“强创新算法”目标。
2. **新算法线**：取消“必须最大复用全部历史结果”的硬约束，只保留可复用的软件基础设施；重新选择任务、信息结构和决策变量。

继续要求新算法同时复用旧结果，会把选题重新拉回 sampler、critic、memory 和 topology regularization，重复已经关闭的路线。

## P0G：干净新项目选题要求

P0G 仍为零训练，目标不是列更多想法，而是只寻找一个满足下列条件的题目：

1. **新的决策对象**：一句话能说明 agent 新决定什么，而不是网络多了什么模块；
2. **真实信息约束**：局部观测、通信代价、时延或失效状态必须对应可执行语义；
3. **可证伪缺口**：在实现前可用小型反例、信息论界或可行性证明说明现方法为何不足；
4. **算法核心不可被 PPO+GNN+GRU 概括**；
5. **至少两个评价环境**：一个可复用 UAV 环境和一个社区标准环境；
6. **P1 成本上限**：3 seeds、每条不超过 1M steps，能在一周内否决；
7. **正式成本上限**：通过 P1 后，完整训练预算原则上不超过 200M environment steps；
8. **失败即停**：不允许连续版本修补。

## 推荐的 P0G 搜索母题

不再限制于“拓扑故障采样”。优先搜索：

> **资源受限、动态失效条件下的异构多智能体任务恢复：策略需要联合决定任务承诺、信息请求与安全降级，而不是被动接受预设故障组。**

该母题是否成立仍需最近邻审查。它不是对 C-line 路由问题的恢复：核心决策对象应是任务承诺与可验证恢复，而非网络流、AoI 或 relay migration。

## 允许复用的资产

- PPO/MAPPO 训练骨干与并发 runner；
- 图观察和角色编码基础组件；
- checkpoint、seed、evaluation tape 和 provenance 审计框架；
- UAV 3DOF 动力学与安全指标实现。

## 禁止复用为新结论的资产

- DRTP/EGTR/GA-EGTR 的正式或历史收益数字；
- 旧 2D、旧 6-UAV 或技术无效实验；
- 任何历史 NO-GO 机制的换名版本；
- 将旧结果合并为新项目的训练重复。
