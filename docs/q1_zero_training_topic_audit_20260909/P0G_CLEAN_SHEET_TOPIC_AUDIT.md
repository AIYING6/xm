## 1. 本轮授权如何改变搜索空间

“可以大修大改”解除的是旧项目接口约束，而不是证据门槛。新项目可以重定义观测、动作、故障可见性和任务过程；可以复用 3DOF 动力学、MAPPO 训练骨干、并发 runner、固定评估带、seed 注册和 provenance 审计，但不得把 DRTP 的历史收益当作新课题证据。

本轮不写代码、不训练，也不把“模块组合”当作创新。候选必须首先回答：**智能体新增决定什么？这个决定为何在现有问题中不可由普通 MAPPO 被动学出？**

## 2. 被排除的两个直觉方向

### 2.1 故障后的动态任务重分配与优雅降级

该问题重要，但最近邻过密。已有工作已经覆盖异构能力约束、故障后的在线重分配、最小约束松弛、任务恢复、能量约束和优雅降级。代表性近邻包括：

- Mayya 等的异构多机器人韧性任务分配：以受损能力为依据重分配，并在资源不足时最小化任务约束松弛；
- Notomista 等发表于 IEEE T-RO 的韧性与能量感知任务分配：同时考虑能力、组件故障和在线分配，并含真实机器人实验；
- 同时任务分配与不确定规划：采用 MDP/LTL 并给出失败后的概率保证；
- 近年的长航时异构多机器人任务分配：在机器人故障、延误和新任务出现时修复或重算计划。

如果本项目仅增加 assignment head、abort 动作或 capability mask，论文会落入成熟 MRTA/规划邻域，且难以证明 MARL 是必要的。

**裁决：** `NO_GO_CROWDED_DECISION_OBJECT`。

## 3. 条件放行候选：主动故障辨识—协同控制

### 3.1 暂定问题

在异构 UAV 协作中，消息缺失可能由链路故障、超距、丢包、上游未观测到目标或任务动作未完成引起。若故障标签不直接提供给 actor，同一个局部快照可以对应不同潜在原因，而这些原因要求不同的后续动作。

新问题不是“如何在已知故障下更鲁棒”，而是：

> **当协同失效原因不可直接观测时，智能体应何时牺牲即时任务收益，执行能区分故障假设的物理探测动作，并在有限诊断预算下恢复协同？**

### 3.2 新的决策对象

每个智能体除任务控制动作外，还必须决定是否进入一个可执行的诊断性机动或握手过程。诊断动作必须改变未来观测在不同故障假设下的可分性，而不是增加一个虚构的“查看故障标签”按钮。

例：中继机短时接近预定通信边界或执行定向握手。如果消息恢复，更支持超距/遮挡假设；如果合法链路条件已满足但仍无消息，更支持节点/链路失效假设。探测会消耗时间、能量并扰动编队，因此存在真实的诊断—任务权衡。

### 3.3 为什么不是 GNN+GRU 换名

普通循环策略只能被动压缩历史；它不显式选择能提高故障可辨识性的动作。候选算法的核心必须是：

1. 维护对有限故障假设的合法 belief；
2. 估计候选动作对假设后验的预期收缩；
3. 在任务价值、诊断价值和安全约束之间进行联合选择；
4. 当假设不可辨识时给出不可辨识证书或保守动作边界。

若最终实现退化为“GRU + fault classification auxiliary loss”或“information-gain reward”，本候选自动失败。

## 4. 最近邻压力与剩余缺口

| 最近邻领域 | 已覆盖内容 | 与候选的剩余差异 | 风险 |
|---|---|---|---|
| 主动故障诊断 / FIERL | 用控制输入提升被动故障检测器信息量；受约束 RL 设计诊断控制 | 主要是单系统/执行器故障，不含分散协同与隐蔽链路原因 | 中 |
| 多智能体主动假设检验 | 多 agent 学习采样/停止规则以降低 Bayes risk | 目标是诊断本身，未联合具身任务控制和协同恢复 | 中 |
| 多机器人主动信息获取 | 在通信约束下协调探测以最大化信息目标 | 通常探测外部目标，而非辨识协同链路/节点故障 | 中 |
| Ask-type communication | 执行期权衡请求信息的价值与通信成本 | 决策对象是通信请求，不是通过物理动作制造可辨识观测 | 中—高 |
| 鲁棒通信 MARL | 估计消息可靠性、衰减可疑消息影响 | 多为被动防御，不主动设计诊断动作 | 中 |
| MAS 故障诊断 | 诊断计划和协调故障，已有二十年模型诊断积累 | 多数将诊断与任务控制分开；主动 troubleshooting 仍被综述列为开放方向 | 中—高 |
| 间歇通信下的 MARL | 重建丢失信息或学习鲁棒策略 | 侧重补全/鲁棒执行，不区分不可观测的失败原因 | 中 |

当前检索没有证明“世界首创”。它只支持一个较窄判断：**精确交叉点尚未被单篇近邻完整覆盖，但相邻领域都很成熟，必须依靠可辨识性定义和诊断动作的任务内语义建立贡献，不能依靠组合新颖性。**

## 5. 可证伪核心

### 5.1 P1 必须先构造严格反例

构造至少两个潜在故障状态 \(h_1,h_2\)，满足：

1. 在不执行探测动作时，actor 的合法历史分布相同或近似不可分；
2. 两个状态的最优任务动作不同；
3. 存在一个合法探测动作 \(a^p\)，使后续观测分布的总变差距离或 KL 距离严格增大；
4. 探测成本非零，因此“始终探测”不是最优策略。

若上述四项不能在小型解析模型和环境单元测试中同时成立，则本方向立即关闭。

### 5.2 候选目标

令 \(b_t(h)\) 为 agent 对故障假设 \(h\) 的 belief，\(a_t\) 为物理动作。诊断价值不应是任意内在奖励，而应由动作条件下的后验收缩定义，例如：

\[
\mathcal I_t(a)=\mathbb E_{o_{t+1}\sim p(\cdot\mid b_t,a)}
\left[D_{\mathrm{KL}}(b_{t+1}\Vert b_t)\right].
\]

联合决策只在冻结安全集 \(\mathcal A_{\mathrm{safe}}(x_t)\) 内选择：

\[
a_t^*=\arg\max_{a\in\mathcal A_{\mathrm{safe}}(x_t)}
\left(Q_{\mathrm{task}}(b_t,a)+\lambda_t\mathcal I_t(a)\right),
\]

其中 \(\lambda_t\) 必须由剩余诊断预算、任务时限或 belief 风险决定，而不是调参得到的常数故事。

这只是 P1 的数学靶点，不构成已完成算法。

## 6. 实验闭环草案

### 6.1 环境一：异构 UAV 主环境

复用 `envs/uav_intercept_3d_env.py` 的 3DOF 动力学、角色异构性、碰撞/边界指标、消息年龄和通信邻接。需要重写：

- actor 不直接观察 `failed_blue_agent` 或故障真值；
- 加入至少两种在短历史内可混淆、但可通过合法机动区分的失效原因；
- 增加有真实时间/能量代价的诊断性机动或握手；
- 任务奖励、诊断代价和安全指标分开记录。

### 6.2 环境二：社区可识别的 Dec-POMDP / MARL 基准

优先顺序：

1. 标准 Dec-Tiger 的多智能体主动监听变体，用于验证 belief 与主动辨识部分；
2. PettingZoo MPE 的 cooperative task 加冻结的隐故障 wrapper，用于验证连续空间协同；
3. 若前两者无法保持同一科学问题，候选关闭，不以自建第二环境冒充外部验证。

### 6.3 必要对照

- recurrent MAPPO：具有相同历史容量，但无主动诊断目标；
- passive belief MAPPO：维护 belief，但不能选择诊断动作；
- always-probe / never-probe：验证探测成本与必要性；
- oracle-fault policy：只作为信息上界，不作为公平主基线；
- 候选完整方法。

### 6.4 端点

- 任务：return、success、timeout、完成时间；
- 诊断：fault identification accuracy、time-to-identification、posterior calibration；
- 代价：probe count、energy/time cost；
- 安全：collision、constraint violation；
- 可靠性：seed-level mean、median、lower tail 和 catastrophic failure count。

训练 seed 是独立统计单位；episode 只能用于估计每个 seed 的端点。

## 7. 成本与复用

| 项目 | 复用程度 | 工作量 |
|---|---:|---:|
| 3DOF 动力学与安全检查 | 高 | 低 |
| MAPPO/PPO、并发 runner、checkpoint | 高 | 低 |
| 当前 actor observation | 中 | 中：需移除故障真值泄漏并增加诊断结果 |
| 当前动作接口 | 低—中 | 中—高：需定义可执行探测动作 |
| DRTP sampler 与历史结果 | 不复用 | 无 |
| 固定 tape、seed registry、provenance | 高 | 低 |
| 第二基准环境 | 低 | 中 |

预计在通过 P1 后，P2 pilot 为 5 个方法中的关键三项、3 seeds、每条不超过 1M steps；总预算上限约 9–15M steps。只有明确观察到“被动历史基线失败、主动方法改善且探测成本非零”的三联证据，才进入不超过 200M steps 的正式阶段。

## 8. 质量判断

- **强二区潜力：** 有，但条件严格。必须获得可辨识性反例、匹配 recurrent/belief 对照、两个环境和 seed-level 重复证据。
- **一区潜力：** 当前不足。至少还需要一个非平凡理论结果（如有限诊断预算下的可辨识/遗憾界或安全可达性保证）以及真实系统或高保真硬件在环验证。
- **时间风险：** 中高。主要风险是环境语义设计，而不是 GPU 训练。
- **最大失败模式：** 把主动诊断简化成辅助分类损失或奖励塑形；那将失去新决策对象。

正式关闭“任务重分配/优雅降级”和“通信路由/请求”两个直觉候选。只允许“主动故障辨识—协同控制”进入 P1，且 P1 仍然是零训练形式化审查，不授权算法实现和云端训练。
