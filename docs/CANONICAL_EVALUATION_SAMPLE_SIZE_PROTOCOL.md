# Canonical evaluation sample-size protocol

Before canonical results exist, freeze equal evaluation counts at **300 episodes per method × seed × scenario**, with the same paired episode tape IDs across methods. The primary scenario set is the four audited fixed failure scenarios. Primary aggregation is seed-level first, with episode-level resampling nested within seed/scenario. No additional episodes may be added because confidence intervals are wide.

This N is a pre-result design choice and is not based on observed canonical outcomes.
