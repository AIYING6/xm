# Scientific Figure Design Protocol

## Task contract

- Goal: make each retained main figure answer one scientific reading question.
- Constraints: only canonical numerical data and code-traceable schematic facts; no generative scientific evidence.
- Done when: figure contract, data source, script, text, and element audit exist for every final figure.

## Visual diagnostic decisions

1. The primary visual difference is temporal concentration of recovery, not a universal terminal-success gap. Therefore KM/RMST must lead; Pareto and conditional-time plots cannot headline the paper.
2. Nine-method KM is cognitively crowded. The final main view should emphasize Full, MAPPO, HAPPO, and wider single graph, with ablations in a separate panel/table or Supplementary.
3. OOD is a boundary, not a result headline. Use one compact family-level display/table; move cell-level and ceiling diagnostics to Supplementary.
4. Gate Prior figure requires both with-prior and without-prior curves plus cross-seed representation. The current single orange line is not admissible evidence for its caption.
5. The current relation schematic is inadmissible until it matches the implemented three-relation set exactly.

## Figure contracts required before regeneration

Every final figure must record: claim; data source; statistical unit; script; transformations; panel-specific message; source-data location; Chinese labels; vector export; and element-level fact audit.
