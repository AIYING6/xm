## Zotero and external discovery

- A Zotero connector/skill is not available in the current installed-skill inventory. Therefore it cannot be claimed as the literature-management evidence layer.
- Use external academic search for discovery, then `nature-ref-verifier` for identity verification and a local claim-reference matrix for support/contradiction/closest-work provenance.
- If Zotero is installed and authenticated later, add it as a controlled read-first library; do not use it as a substitute for external discovery.

## Skill maturity / control

Project evidence, frozen protocols, and code remain the scientific source of truth. Skills may organize, audit, search, or polish; they may not change numerical conclusions, infer methods absent from code, or introduce unverified citations.
