# 从问题到结论的论证闭环与结果叙事计划

## 一、闭环

**问题。** 在继电依赖的三 UAV 协作任务中，故障并非抽象噪声：它改变哪些目标信息可合法送达攻击角色，以及哪些任务支撑路径仍有效。

**方法干预。** 固定策略骨干、PPO、奖励、观测、动作、名义质量、故障支持与预算，只把六个冻结故障组的训练抽样由均匀条件质量改为根据完成回报相对名义回报更新的有界概率分布。

**受控证据。** 前瞻性配对五种子 E1 终点评估显示，DRTP 在预定义的 F0、跨条件平均和跨条件最差回报上呈正向配对差异，同时超时下降、碰撞略升、约束违规保持为零。

**结论。** 在该实验合同下，训练期的有界故障组重加权与故障端点的更高任务回报和更低超时相关；它是一种可复现实验干预，不是对所有拓扑故障、每个随机种子或真实飞行安全的保证。

## 二、暂定题目与论文论题

**暂定题目：**

**有限信息继电故障下三无人机协作任务的有界自适应训练暴露重加权：一项配对终点评估研究**

**单句论题：**

在一个固定的三 UAV 继电依赖协作合同中，若保持策略、优化、信息边界与条件支持不变，仅将故障组训练暴露从均匀分配替换为有界自适应分配，则最终故障任务端点可发生可重复的队列内变化，但这种结果受训练队列、保留条件和可靠性权衡限制。

## 三、最多三项可检验贡献

1. **受控设计贡献：** 构建一个将合法信息路径、继电节点故障和固定终点评估同时绑定的三 UAV 试验合同，使“训练暴露分配”成为可隔离的干预变量。
2. **方法干预贡献：** 在不改变策略网络、PPO、奖励、观测或执行期环境动态的条件下，实现并审计名义相对完成回报驱动的有界故障组重加权。
3. **经验贡献：** 在前瞻性五种子配对端点评估中报告任务回报、超时、碰撞、触发有效性和训练暴露遥测的联合结果，并以独立/历史队列与保留结构端点界定外推范围。

## 四、章节级大纲

1. 引言：提出有限信息继电故障中的训练暴露分配问题，而非泛称“拓扑鲁棒性”。
2. 问题与实验契约：定义环境信息边界、条件组、固定项、统计单位与主要对照。
3. 有界自适应故障组重加权：定义输入、输出、难度、更新和约束；明确不改变的内容。
4. 实验设置：分层说明 E1、E2、E3、E4；禁止合并队列与 episode 伪重复。
5. 结果：先 E1 主比较，再可靠性权衡、遥测、A/B 和结构保留测试，最后外部参考。
6. 讨论与局限：区分可归因、可描述和未知机制；报告历史不利实现与无机制结论。
7. 结论：给出受合同限制的结论及后续证据要求。

## 六、结果叙事顺序

1. 先证明所比较的变量确实只是一项：故障组训练暴露分配。
2. 再报告 E1 主要配对结果，以训练种子为单位；表中完整展示五个差异而不是仅给均值。
3. 紧接报告超时、碰撞、约束和故障触发，避免把 `J` 的改善写成安全改善。
4. 用采样遥测验证干预被执行；明确它不是机制因果链。
5. 将 A/B、结构保留测试与 PLR-style 比较放入“外部定位和边界”而非主结果替代品。
6. 主动报告历史 held-out 的失败 seed 和 B5 机制 NO-GO，说明本文的结论为何必须保持在合同范围内。
