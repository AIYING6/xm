# Paper Manifest Runner

Generated: 2026-07-24

## Purpose

`scripts/run_paper_manifest.py` executes selected rows from `results/paper_command_manifest.csv` and records an experiment ledger.

It is meant for long training and evaluation runs where manual command execution is easy to lose track of.

## Outputs

Default status ledger:

```text
results/paper_manifest_run_status.csv
```

Default logs:

```text
results/paper_manifest_logs/
```

Each completed row records:

- manifest row index;
- kind, mode, method, seed;
- command;
- UTC start and finish time;
- duration;
- return code;
- stdout/stderr log file paths.

## Example

Dry-run the first ready training row:

```text
python scripts/run_paper_manifest.py --kind train --status ready --limit 1 --dry-run
```

Run only MAPPO seed 0 from the current manifest with the active Python interpreter:

```text
python scripts/run_paper_manifest.py --kind train --method mappo --seed 0 --status ready --limit 1
```

Run validation sweeps after training:

```text
python scripts/run_paper_manifest.py --kind validation_sweep --status ready_after_training
```

Run test sweeps only after validation checkpoint selection exists:

```text
python scripts/run_paper_manifest.py --kind test_sweep --status ready_after_training
```

## Rule

The runner does not create the experimental protocol. It only executes the audited command manifest and preserves run status for reproducibility.

For launch-readiness checks, use `probe_20` commands generated by `scripts/generate_paper_commands.py`. Probe results are engineering diagnostics only and must not be reported as paper evidence.
