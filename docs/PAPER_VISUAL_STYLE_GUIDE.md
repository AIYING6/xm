# Paper Visual Style Guide (Initial)

- Language: Simplified Chinese for titles, axes, legends, captions, annotations; retain EA-RG, MAPPO, HAPPO, RMST and symbols.
- Typography: one sans-serif family that renders Chinese reliably; units and statistical symbols remain roman/math as appropriate.
- Identity: methods require marker/line-style redundancy, not color alone; Full EA-RG receives one consistent primary color.
- Evidence: show uncertainty only when generated from the canonical procedure; label training-seed unit and evaluation population.
- Layout: panel labels `(a)`, `(b)`; direct labels where they reduce legend load; avoid nine-method legends in a single primary panel.
- Exports: reproducible script, source CSV, vector PDF/SVG, and 300-dpi+ raster fallback.
- Prohibited: decorative pseudo-3D, unsupported arrows, relation types absent from code, or visual emphasis that contradicts P1/P2/P3/P4 priority.
