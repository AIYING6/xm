# P2.6 minimal learner correctness patch

The historical P2 global actor is retained as forensic evidence. P2.6 adds a
separate corrected learner with independent Scout, Relay and Terminal policy
bodies; instances share only their role's actor. Relay has exactly one
non-trainable PASS/IDLE outcome. The centralized critic, PPO configuration,
environment semantics, reward, deadline and R/C/I taxonomy are unchanged.

P2.6 permits technical Q0 only. It does not authorize P2-R or any formal
training.
