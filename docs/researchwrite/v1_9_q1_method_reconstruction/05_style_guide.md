# v1.9 Style Guide

## Claim stance

- Write “tests whether” before the confirmatory result and “was associated
  with” before a causal mechanism is independently supported.
- Use “stable task-chain establishment,” not “true recovery.”
- Describe v1.8 as a fairness/protocol repair line, not as v1.9 evidence.

## Preferred terminology

- recipient-specific legal actor information
- provenance-conditioned relation factorization
- relation conflict / relation agreement
- delivered/cache-valid packet
- parameter-matched comparator
- mechanism diagnostic / confirmatory evaluation

## Prohibited wording

- “all metrics outperform”
- “obviously novel”
- “Role Gate is a key innovation” (until independent evidence exists)
- “robust” without reporting the full pre-specified severity grid
- “recovery” where the frozen endpoint is establishment after failure onset

## Narrative rule

The paper’s value comes from a precise conditional statement with a hard
counterfactual, not from a long list of components or selectively favorable
metrics.
