# Parameter-Matched Single-Graph design

The final canonical structural comparator is a merged-adjacency Single-Graph with hidden width 115. It has 116,728 trainable parameters versus Full's 117,302, a relative difference of 0.489%.

It uses ordinary single-graph attention only. It adds no relation labels, relation-specific channels, role-pair gate, task-support semantics, hidden global information, or Full-only message path.
