# Publication positioning options

| Position | Current feasibility | Required wording | What would invalidate it |
|---|---|---|---|
| A. New UTR algorithm | No | Do not use | UTR has no distinct adaptive rule/objective/architecture |
| B. Structured topology-randomization framework | Conditional | “A transparent training framework over a physically constrained topology-failure taxonomy” | If naive randomization or robust samplers perform equivalently and the taxonomy lacks task value |
| C. Benchmark plus strong simple baseline | Feasible now | “A redundant-topology UAV benchmark with a transparent uniform-training reference” | If benchmark semantics are not reproducible or external baselines are absent |

**Chosen position:** C. Position B becomes plausible only after the minimum comparator and
held-out evidence plan is completed. Position A is closed.
