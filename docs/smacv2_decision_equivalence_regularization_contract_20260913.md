# SMACv2 决策等价正则（DER）单候选研究合同

**日期**：2026-09-13  
**状态**：`CLOSED_BY_RESEARCH_SCOPE_20260913 — 不进入训练`
**目的**：为强二区目标只保留一个可证伪候选；本文件不是论文结论，也不把 SMACv2 安装状态当作方法证据。

## 1. 从公开基准自然导出的缺口

SMACv2 以程序化的队伍组成与初始位置生成要求策略面对未见配置；原始论文的动机正是原 SMAC 缺乏足以要求闭环策略的随机性与部分可观测性。对共享去中心化策略而言，未见配置不只是输入数值变化：不同局部实体组合、距离和可用动作掩码会改变同一战术判断所处的表面观测。

本候选只研究如下问题：

> 当两个局部协同决策上下文具有相同的**可行动作排序与关系任务含义**，但来自不同程序化队伍配置时，如何避免策略将配置偶然相关性误学为动作偏好？

这不是 DRTP 的训练条件重加权，不是信用分配，不是角色分配，不是主动探测，也不是单纯给网络换成 GNN/GRU。

## 2. 唯一方法干预：Decision-Equivalence Regularization（DER）

在标准 MAPPO 的 CTDE 训练中，中央 critic 对批内局部决策上下文给出合法动作的优势排序。DER 只在满足以下三个条件的跨配置样本对上增加一致性项：

1. 局部可见实体的相对关系描述匹配（单位类别、相对距离带、可见友/敌计数及局部阶段）；
2. 合法动作集合匹配；
3. critic 的合法动作优势排序一致，且排序间隔超过预先设定的置信阈值。

对这些**决策等价对**，约束 actor 在共同合法动作上的分布接近；其余样本不受该项约束。训练目标为：

\[
\mathcal{L}=\mathcal{L}_{\mathrm{MAPPO}}+
\lambda\,\mathbb{E}_{(x,x')\in\mathcal{E}}
\left[\operatorname{JS}\big(\pi(\cdot\mid x),\pi(\cdot\mid x')\big)\right],
\]

其中 \(\mathcal{E}\) 是由上述三项冻结规则构造的决策等价对集合。该机制的目标不是声称所有几何变换都应不变；它只约束 critic 已判定为同一动作排序的局部决策。

### 与已排除路线的边界

| 路线 | 为什么不作为本文创新 | DER 的不同点 |
|---|---|---|
| 等变 GNN / E2GN2 | 已直接在 SMACv2 报告泛化收益；“使用等变性”不新 | 不预设全局旋转/置换不变性；只对 critic 判定的决策等价上下文施加约束 |
| 普通数据增强 | 对变换隐含一刀切的标签不变假设 | 由可行动作和优势排序筛选，允许非等价配置保持不同决策 |
| GRU / 上下文编码 | 主要解决历史信息整合 | DER 不新增记忆状态；主对照必须是参数匹配 MAPPO-GRU |
| DRTP / curriculum | 改变训练样本出现概率 | DER 不改变任何配置采样概率，只改变同一批轨迹的学习约束 |

## 3. 唯一主要因果比较

保持以下条件一致：SMACv2 场景分布、训练环境步数、PPO 超参数、actor/critic 主干、循环状态、参数预算、随机种子带、评估配置分布和行动掩码。唯一变化为是否加入 DER 损失。

主要比较：`MAPPO-GRU` 对 `MAPPO-GRU + DER`。

外部定位而非主要因果对照：已公开实现且可复现时的等变基线或标准增强基线。它们不得与主要受控比较混写。

## 4. 开跑前四个硬门（一次性设计，避免事后找理由）

| 门 | 最小证据 | 不通过时的处置 |
|---|---|---|
| G0：平台 | 官方 SMACv2 在 `D:\\MARL\\StarCraftII` 可启动；固定训练/测试配置确实不同 | 只修运行时，不讨论方法 |
| G1：现象 | MAPPO-GRU 在同分布未见配置上出现非饱和的训练—测试差距，且至少 3 个短 seed 不是全零/全满 | 不做 DER；基准没有可塑造的泛化缺口 |
| G2：可构对 | 预定义筛选后，每个短 seed 有足够的跨配置决策等价对；其策略分歧非零 | 不做 DER；机制没有作用对象 |
| G3：识别 | 在相同短预算下，DER 对 held-out win rate 或 lower-tail 至少给出方向一致的早期信号，且不以训练性能崩塌换取测试收益 | 不进入 10M；不修改阈值、\(\lambda\) 或测试集补救 |

G0--G3 是**研究可行性门**，不是论文结果。只有全部通过，才冻结正式协议。

## 5. 正式协议（仅在 G0--G3 全通过后启用）

### RQ1：DER 是否改善未见配置协同？

- 主要端点：冻结 held-out configuration distribution 的 win rate；训练 seed 是唯一独立统计单位。
- 次要端点：median、最差 seed、训练样本效率和胜率曲线面积。
- 设计：5 个新 seed，训练/测试配置生成器与 seed 带预先分离。
- 上限表述：仅支持“在所评估的程序化配置分布中改善跨配置表现”；不支持真实 UAV 部署或所有团队组成的保证。

### RQ2：收益是否来自“决策等价”而非额外正则？

必须预先固定两个消融：

1. `Random-Pair DER`：保留相同 pair 数和 JS 系数，但随机跨配置配对；
2. `No-Advantage-Filter DER`：保留关系/掩码匹配，但取消优势排序一致性筛选。

只有完整 DER 同时优于这两个对照，才可将收益归因于所定义的决策等价筛选；否则只能报告“正则化敏感性”。

### RQ3：它与普通配置增强有何不同？

若 G0--G3 通过且公开复现成本可承受，添加 `Configuration-Augmentation MAPPO-GRU`：保持训练配置数和数据量，随机选择跨配置对而不使用 critic 筛选。此项是外部机制定位，不替代 RQ1 的因果对照。

### RQ4：代价是什么？

报告同一硬件、相同并发下的 wall-clock、额外 pair 构造时间和峰值显存。不得把“主干未变”写成“零开销”。

## 6. 预注册失败边界

以下任一结果将终止本候选，而非换阈值或增加训练：

- MAPPO-GRU 已在未见配置上饱和，或不存在稳定训练—测试差距；
- 决策等价对稀少、排序不稳定或 actor 分歧近零；
- 完整 DER 与随机配对/无筛选版本无法区分；
- 收益仅在训练配置出现，或以明显 lower-tail 退化换取均值。

## 7. 当前事实与下一步

截至本文件，SMACv2 Python 包及官方地图源码已放置于 D 盘，但 StarCraft II 客户端尚未被可重复验证；因此 G0 未完成，DER 尚未实现，也没有任何 DER 性能数字。

2026-09-13，研究者决定停止 SMACv2 支线：该路线需要 StarCraft II 作为外部仿真运行时，且与当前 UAV 资产的直接关联不足。此决定不是 G0--G3 中任一科学门的失败；它是研究范围与成本的主动收缩。

因此，不再执行运行时验证、G1/G2 短实验、DER 实现或任何 SMACv2 训练。已下载的 Python 包、地图源码和 Battle.net 启动器仅保留为未使用的工具资产；不得被引用为实验材料、结果或论文证据。
