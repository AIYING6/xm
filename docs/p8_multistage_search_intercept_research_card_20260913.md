# P8：可恢复多阶段搜索—定位—拦截协同任务研究卡

**阶段：** P8-Q0 通过；环境实现前冻结。未授权方法命名、策略训练或论文结论。
**来源：** P6/P7 未通过的零训练审计，以及现有 3DOF 异构 UAV 动力学、通信缓存和约束接口。

## 1. 要解决的具体问题

研究对象不是一般意义的“多 UAV 任务分配”。P8 研究在局部观测和有限合法信息链下，异构团队如何在当前服务与未来不确定目标之间分配角色，使预先执行的**搜索—定位前缀**在目标揭示后真正缩短拦截完成时间。

核心决策为：在未来目标到达前，是否让 Scout 与 Relay 投入公开预测扇区以建立定位链，同时让 Executor 维持当前任务；该决定将消耗真实飞行时间、链路容量或当前服务机会，而非只改变奖励标签。

## 2. P6/P7 的设计教训

P6/P7 表明，若“预置”不能产生一个可完成、可转移的任务前缀，则公开可靠度不会稳定改变最优动作。P8 因而不得将“抵达预测位置”本身作为成功，也不得用额外的“选对扇区”奖励来制造差异。

## 3. 冻结前必须满足的任务事实

P8 环境实现前必须明确并通过 Q0：

1. **物理前缀。** Scout 的搜索覆盖与 Relay 的可用链路共同形成可观察的定位/跟踪里程碑；该里程碑必须降低后续拦截所需时间、所需信息年龄或连续跟踪时长中的至少一项。
2. **角色争用。** 将 Scout/Relay 投入前缀必须减少当前服务的完成机会、链路质量或剩余时间；不得存在同时免费完成当前和未来两项任务的捷径。
3. **信念切换。** 在至少 3/4 个冻结公开状态中，高可靠度预测应使搜索前缀优于保持策略，低可靠度则使保持/替代策略优于搜索前缀。比较使用公开后验分支，绝不读取父轨迹未来真值。
4. **非饱和。** 当前任务、未来任务及两者兼顾均要在不同上下文中可达；任何单一固定团队计划不得覆盖超过 70% 的冻结上下文。
5. **端点完整。** Q0 及后续训练同时记录搜索定位、目标确认、拦截、超时、碰撞、约束违规、能耗和信息年龄；完整任务值不得用单一塑形奖励替代。
6. **反捷径。** 去掉未来不确定性、去掉角色争用或直接公开未来真值后，原本的可靠度驱动动作切换必须消失或显著减弱。

## 4. 候选方法的最低可识别要求

只有 P8 Q0 通过后才定义方法。候选方法必须解决“如何把合法公开后验转化为角色承诺”，而非重命名 MAPPO、DRTP、优先采样、循环网络或加权奖励。其最小对照集为：

- 同容量前馈 MAPPO；
- 同容量合法历史/循环 MAPPO；
- 后验语义置换但容量、输入维度和优化完全匹配的控制；
- 没有阶段性承诺目标的 MAPPO 控制。

## 5. 文献定位边界

现有工作已广泛覆盖多 UAV 动态目标分配、协同搜索和部分可观测导航。因此，P8 的潜在贡献不能写成“将 MARL 用于 UAV 搜索/分配”，而只能建立在**可恢复的阶段性信息前缀与物理角色承诺耦合**被受控识别的前提上。该判断需在后续正式文献综述中逐篇核验。

## 6. 下一步

P8-Q0 已使用现有 3DOF 飞行动力学、真实通信距离和两个公开团队计划完成。冻结结果位于 `results/development/pscr_p8_search_prefix_q0_fix1_20260913/PSCR_P8_REPORT.json`：高可靠度下搜索前缀的后验任务值为 1.4455，高于保持方案的 1.12375；低可靠度下保持方案为 2.11375，高于搜索前缀的 1.0495。两个方向均在 4/4 个冻结公开状态出现，结果为 `PSCR_P8_IDENTIFIABILITY_PASS`。

该结果只证明任务存在物理、公开信息闭合的角色分配取舍；并不证明任何学习方法有效。下一步授权范围仅为：将该冻结机制实现为标准环境、补充环境级信息边界与端点审计、并运行可学习性基线；不得直接提出新算法或进行正式大规模训练。
